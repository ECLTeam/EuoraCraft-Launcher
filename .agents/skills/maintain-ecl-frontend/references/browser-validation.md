# 浏览器视觉验收

## 目录

- 准备
- 基准页面
- 尺寸与主题
- 检查清单

## 准备

在 `frontend/` 运行：

```powershell
pnpm build:showcase
pnpm showcase --host 127.0.0.1
```

优先使用真实浏览器查看和操作 Showcase。需要可复查证据时，用 Chrome/Edge headless 截图；不要只依赖单元测试或 DOM 快照判断视觉质量。

## 基准页面

至少打开目标页和两个同类页面：

- `/#/`：游戏首页。
- `/#/versions`：实例管理。
- `/#/download`：实例下载。
- `/#/plugins`：插件管理。
- `/#/settings/general`：设置。
- `/#/connect`：联机。

账户管理和衣柜从游戏页进入；检查全屏容器、双栏比例、工具栏和资源卡密度。

## 尺寸与主题

- 主验收：950×610，与桌面应用常用窗口一致。
- 窄窗口：760×600 或项目允许的最小宽度。
- 至少检查浅色和深色。
- 项目启用背景图片时再检查一次表面透明度、文字对比度和边界可见性。

截图应覆盖入口、加载/错误、内容和禁用状态；交互状态不能只看初始页面。

## 检查清单

- 主表面数量和页面原型是否与基准页一致。
- 页面标题、工具栏、列表和表单是否沿同一网格对齐。
- 控件高度是否接近同类页面，而非用大尺寸填空。
- 滚动条是否只出现在预期 viewport；是否有水平溢出。
- 背景图片是否穿透过强或被不透明白块完全遮住。
- 浅色/深色下边框、次级文字、禁用态是否可辨。
- hover、focus、pressed 是否克制且不造成布局跳动。
- 中英文切换后标题和按钮是否截断。

发现问题时先调整结构和密度，重新截图对比，再处理装饰细节。
