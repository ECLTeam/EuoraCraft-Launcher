# ECL 可视化主题设计使用指南

本文介绍如何使用 EuoraCraft Launcher 的多窗口主题设计器、预设库、插件插槽可视化和 `.ecltheme` 文件。插件开发者可继续阅读文末的扩展说明；完整数据格式见 [主题与插件外观扩展协议](../protocols/theme-plugin-protocol.md)。

## 1. 打开主题设计器

1. 打开启动器的“设置”。
2. 进入“通用”页面，在“外观”区域找到“可视化主题设计”。
3. 点击“打开主题设计控制台”。
4. 启动器会保留主窗口当前页面，并打开独立的 `ECL Theme Studio` 窗口。

此时两个窗口分工如下：

- 主窗口是实时画布，用于切换页面、点选组件和查看效果。
- 主题设计控制台用于选择作用范围、填写样式、管理效果、撤销、保存和查看插件插槽。
- 两个窗口连接同一个后端设计会话；控制台改值后，主窗口会立即预览。

设计控制台是独立系统窗口，可以自由移动和调整大小，不会自动吸附到主窗口。自定义标题栏支持拖动、最小化和关闭。

> 修改只会先写入设计草稿。点击“保存”之前，不会覆盖已保存的主题预设。

## 2. 点选组件与浏览页面

进入设计模式后，主窗口底部会出现画布工具栏。

- “点选模式”：点击带有主题节点的卡片、按钮或页面区域，将其设为当前节点。点击会被设计器拦截，不会执行该控件原本的业务操作。
- “暂停点选”：暂时恢复页面正常交互，可切换路由、滚动页面、打开需要查看的区域。
- “继续点选”：重新进入点选状态。
- `Esc`：快速暂停点选。

选中框会跟随目标组件滚动、动画和尺寸变化。若需要设计另一个页面，先暂停点选，进入目标页面，再继续点选。

并非所有纯文本或装饰元素都能单独选择。一个区域只有声明了稳定主题节点时，才会成为可编辑目标；否则应选择它所属的卡片或上层组件。

## 3. 理解作用范围

点选组件后，可在控制台的“当前节点”区域切换作用范围：

| 作用范围 | 影响对象 | 典型用途 |
| --- | --- | --- |
| 全局 Token | 整个启动器以及所有窗口 | 主色、统一圆角、字体、表面阴影 |
| 组件类型 | 同类型的所有组件 | 统一修改全部卡片或同类按钮 |
| 页面节点 | 当前稳定节点 | 只修改某个页面上的指定区域 |
| 数据实例 | 某个具体业务实例 | 只修改某个游戏实例或重复列表项 |

某个范围不可用时，其选项会变灰。例如，节点没有实例 key 时不能选择“数据实例”。

最终样式按以下顺序覆盖，越靠后优先级越高：

`内置基础样式 → 全局 Token → 组件类型 → 页面节点 → 数据实例 → 当前设计草稿`

控制台会在属性旁显示“基础”“组件”“节点”“实例”或“当前草稿”等来源，帮助判断最终值来自哪一层。未设置的属性会继续继承较低层，而不是被清空。

## 4. 修改外观

### 全局设置

作用范围为“全局 Token”时，可以调整：

- 主色，例如 `#5b6ff5`。
- 卡片圆角，例如 `10px`。
- 控件圆角，例如 `6px`。
- 界面字体，例如 `HarmonyOS Sans SC`。
- 表面阴影，例如 `0 8px 24px rgba(20,30,55,.12)`。

### 组件、节点和实例设置

选择非全局范围后，可以调整：

- 背景与文字颜色。
- 边框颜色和圆角。
- 阴影与玻璃模糊。
- 透明度。
- Hover 变换和过渡。
- 键盘焦点颜色与宽度。

输入值使用普通 CSS 值，但不要加入末尾分号。例如应填写 `translateY(-2px)`，而不是 `translateY(-2px);`。

主题系统会拒绝危险属性，包括任意定位、任意层级、事件行为、`pointer-events` 和不受限制的宽高。不能通过主题输入任意 CSS、JavaScript 或业务内容。

### 效果配方

“效果配方”可以为当前作用目标添加：

- 阴影
- 玻璃
- 渐变
- 边框
- 滤镜
- Hover 动效

效果仍会经过安全属性白名单编译。系统启用“减少动态效果”时，主题动画和过渡会自动降级。

控制台也会提示部分可访问性风险，例如文字对比度过低、焦点轮廓不可见、模糊过强或动画时间过长。

## 5. 显示插件插槽

可以从以下任一位置开启插槽显示：

- 主窗口底部工具栏中的“显示插槽”。
- 设计控制台“插件插槽”区域中的“显示画布插槽”。

开启后，主画布会显示插槽锚点：

- 蓝色虚线表示当前为空的插槽。
- 绿色实线表示已有插件内容的插槽。
- 标签显示插槽 ID；重复插槽还会显示对应的上下文 key。
- 标记使用独立固定叠层绘制，不会撑开页面或改变滚动条。

设计控制台会同时列出插槽 ID、当前上下文数量和占用数量。点击“复制”可复制完整 ID，供插件清单或注入代码使用。

如果某个插槽属于尚未打开的弹窗或未挂载的页面，它不会出现在当前画布上；进入对应页面后，清单会自动同步。

## 6. 撤销、保存和关闭

- “撤销/重做”：只操作当前设计会话的草稿历史。
- “保存”：保存当前预设并立即将其设为启用主题。
- “另存为”：生成新的用户主题 ID，保留原预设不变，并启用新主题。
- “放弃”：退出本次会话并恢复已保存主题。

设计过程中会保存恢复检查点。关闭独立控制台且存在未保存修改时，可选择保存、保留恢复草稿或彻底放弃。控制台意外关闭时，主窗口会退出点选模式，但草稿可以在下次进入设计模式时恢复。

关闭主窗口会一并关闭它创建的主题控制台和插件窗口。

## 7. 主题预设库

设置页的“主题预设库”提供以下操作：

- “应用”：启用选中的预设。
- “导入 `.ecltheme`”：从本地导入主题包。
- “导出”：将预设和资源打包为 `.ecltheme`。
- “删除”：删除未启用的用户主题；内置只读主题不能删除。

导出时会询问是否包含实例级覆盖。实例覆盖可能间接暴露本机实例名称或标识；分享主题时建议选择“不包含”。

导入主题与现有 ID 冲突时，默认会创建副本。主题引用的插件缺失时，未知插件扩展配置会被保留；安装或重新启用相应插件后可再次生效。

## 8. `.ecltheme` 与资源

`.ecltheme` 是 ZIP 容器，核心内容包括：

```text
example.ecltheme
├── manifest.json
├── theme.json
└── assets/
    ├── background.webp
    ├── decoration.svg
    └── ui-font.woff2
```

支持的资源类型：

- 位图：PNG、JPEG、WebP、GIF、BMP。
- 矢量图：安全的静态 SVG。
- 字体：WOFF2。

主题包最多包含 128 个文件，压缩包最大 50 MiB，解压后最大 100 MiB。所有文件都通过 SHA-256 校验，并检查路径穿越。

### SVG 使用规则

支持 SVG，但只支持静态、本地、安全的图形：

- 单个 SVG 最大 5 MiB。
- 禁止 DTD、XML 实体、脚本和事件属性。
- 禁止 `foreignObject`、`iframe`、`object`、音视频等标签。
- 外部 `href`、外部图片和危险 `url(...)` 会被移除。
- SVG 不能执行插件逻辑，也不能请求网络资源。

建议将字体转为路径或随主题附带 WOFF2，避免不同系统缺少字体时导致图形变化。

## 9. 插件作者：贡献主题和窗口

插件可在 `plugin.json` 中声明预设、效果、Token、节点和受控窗口：

```json
{
  "permissions": [
    { "scope": "theme", "action": "read", "resource": "preset:*" },
    { "scope": "theme", "action": "read", "resource": "effect:*" },
    { "scope": "theme", "action": "read", "resource": "token:*" },
    { "scope": "theme", "action": "read", "resource": "node:*" },
    { "scope": "ui", "action": "write", "resource": "window:inspector" }
  ],
  "contributes": {
    "themePresets": ["themes/aurora.json"],
    "themeEffects": ["themes/effects.json"],
    "themeTokens": ["themes/tokens.json"],
    "themeNodes": ["themes/nodes.json"],
    "windows": [
      {
        "id": "inspector",
        "title": "示例检查器",
        "route": "/plugin/example/inspector",
        "singleton": true,
        "width": 720,
        "height": 560,
        "settings": ["accent"],
        "commands": ["refresh"],
        "events": ["example:data_changed"],
        "dataSchema": {
          "read": ["plugin.settings.accent"],
          "write": ["plugin.settings.accent"]
        }
      }
    ]
  }
}
```

要求：

- 主题预设 ID 使用 `plugin.<插件名>.<预设名>`。
- 效果、Token 和节点 ID 以 `<插件名>.` 开头。
- 插件窗口只能打开本地 `/plugin/<插件名>/...` 路由，不能打开任意外部网页。
- 插件窗口只能访问清单声明的设置、命令、事件和数据字段。
- 插件被禁用或卸载时，其窗口和运行时注入会被清理；主题扩展配置会保留，以便恢复插件后重新启用。

## 10. 插件作者：向插槽注入内容

普通 HTML 注入示例：

```python
self.inject_html(
    "plugin-slot-task-queue-item-actions",
    "<button type='button'>详情</button>",
    key="details-action",
    context_key=task_id,
)
```

Vue 插槽组件示例：

```python
self.register_vue_slot(
    "plugin-slot-game-right-top",
    "example-server-status",
    template="<div class='server-status'>服务器在线</div>",
    style=".server-status { color: var(--success); }",
)
```

`context_key` 用于重复列表中的单个插槽实例；不传时，注入会应用到该插槽的全部上下文。开发时可打开“显示画布插槽”，复制准确的插槽 ID，并确认目标插槽是否已占用。

插件注入的 HTML 仍会经过前端安全处理。不要依赖内联脚本、任意宿主状态访问或直接编辑 `setting.json`。

## 11. 常见问题

### 点击组件没有反应

确认主窗口工具栏显示“点选模式”。若当前为“浏览模式”，点击“继续点选”。目标也必须是已声明的主题节点。

### 点选后按钮无法正常使用

这是点选模式的预期行为。点击“暂停点选”或按 `Esc` 后再操作按钮。

### 显示插槽后看不到标记

确认当前页面实际挂载了插槽。隐藏弹窗和其他路由的插槽不会显示；切换到对应页面后会自动刷新。

### 控制台显示 0 个上下文

等待主窗口完成页面渲染，或暂停点选后切换一次页面。插槽清单由主窗口同步到共享设计会话，主窗口关闭后不会继续更新。

### 独立控制台打开失败或一直连接

完全退出并重新启动启动器。仅刷新 Vite 页面不会重新加载后端窗口注册、Tauri capability 或原生窗口资源。随后查看日志中的“已创建受控窗口”和“前端窗口已就绪”。

### 修改后界面出现异常

先使用“撤销”。若无法恢复，点击“放弃”回到已保存预设。不要在 CSS 值中加入分号、花括号、`url(...)` 或脚本表达式。

### 设置页出现额外滚动条或页面偏移

插槽标记和选中框不应参与页面布局。若仍可复现，请记录当前页面、被选中的节点、是否开启插槽显示，并附带截图和前端日志。

## 12. 当前边界

主题设计器用于受控外观编辑，不提供以下能力：

- 页面结构拖拽或导航重排。
- 任意全局 CSS、JavaScript 或事件修改。
- 任意修改 Pinia、后端对象或全部宿主配置的数据检查器。
- 外部网页插件窗口、在线主题市场或云同步。
- WebGL 主题效果。

这些限制用于保证主题和插件失效时不会导致启动器白屏、业务功能被覆盖或宿主配置被越权修改。
