# 开发模式与文件热重载

## 开关与范围

插件页“开发模式”仅在本次启动器进程有效，重启后默认关闭。开启时将已经审阅并启用的第三方目录插件转为稳定副本运行，再开始检测实际安装目录。未批准或被禁用的插件不会自动启用；以后由用户正常启用的目录插件也可纳入本次会话。

归档版本目录和发行资源中的系统插件不受开发监听。当前没有外部源码目录挂载或原始导入目录同步；使用“打开插件目录”编辑真正的安装副本。

## 明确拒绝

```json
{
    "name": "no_reload_example",
    "api_version": 2,
    "version": "1.0.0",
    "entry_point": "main:Plugin",
    "supports_hot_reload": false,
    "permissions": []
}
```

省略或严格布尔 `true` 表示允许。`false` 不因源码保存自动切换版本，状态显示“插件拒绝热重载”；用户仍可手动重载。字符串 `"false"`、数字和 null 无效。

本字段由宿主解析，不需要执行插件才能发现。监听清单中的策略变化；改回 `true` 后仍需满足授权、启用意图和文件稳定条件。

## 文件与防抖

默认每 750 ms 检查一次文件集合及元数据，变化后再稳定等待 750 ms。连续保存合并为最新候选，最终按字节摘要确认；仅改变时间戳而字节相同，不重启 Worker。

清单、Python、前端、资源、锁文件等普通分发文件均在文件集中。开发输入排除 `.git`、`node_modules`、`.venv`、`venv`、`__pycache__`、`.pytest_cache`、`.mypy_cache`、`.ruff_cache`，以及 `.pyc`、`.pyo`、`.swp`、`.swo`、`.tmp`、`~` 临时文件。

监听和副本准备共用上述规则。正式归档校验不因此放宽。依赖应通过锁与 wheel 提供，运行数据写入插件私有空间；不要在代码目录创建持续变化的日志或把依赖构建产物误当成前端资源。

新增、删除、重命名和编辑器原子保存都视为文件集合变化。源码必须满足既有数量、大小、合法路径及无链接要求。宿主二次比较源文件和副本字节，并预编译 Python 语法，不在准备阶段执行入口。

## 会话信任

自动换代只沿用本会话已批准范围。权限声明、站点、身份、入口、独立前端声明、插件依赖、Python 依赖、锁、wheel 或 ABI 边界发生变化时，暂停并重新审阅。

普通运行仍按完整内容摘要校验。开发运行也校验自己的执行副本，使用原授权记录作为范围上限，不向新代码摘要写永久 allow。原授权被撤销或发生版本变化时，开发准入失效。

关闭模式会撤销所有开发凭据，停止开发 Worker，并恢复源目录的普通审阅资格。当前源码与原批准内容不同时，需要用户重新审阅才能在普通模式启动；已经保存的配置和私有文件保留。

## 运行切换

| 状态           | 含义与处理                                       |
| -------------- | ------------------------------------------------ |
| 准备版本       | 校验稳定源码并生成独占副本；准备失败可保留旧运行 |
| 正在重载       | 停止并清理旧代次，之后才启动新 Worker            |
| 监听中         | 当前副本有效，等待下一次变化                     |
| 插件拒绝热重载 | 不自动换代，可手动重载                           |
| 需要重新审阅   | 声明或授权边界变化，按普通流程重新审阅           |
| 等待清理       | 旧进程或宿主资源尚未释放，不能并行启动新版       |
| 重载失败       | 查看稳定错误码，修正源文件或明确重试             |
| 已禁用         | 用户关闭了该插件，后续保存不得重新启用它         |

每个安装至多一个有效 Worker。命令、订阅、面板、插槽、认证注册、联机会话及独立窗口随旧运行失效，新版必须重新注册。内存变量不迁移，旧 `operation_ref`、窗口引用、Java 引用等不能跨运行使用。

已启动的 Minecraft 不因热重载强杀；插件关闭也不保证已经提交的任务回滚。独立窗口会关闭，若需要重新打开，应由新运行按自身生命周期重新发起。

新版本语法准备失败可以继续使用旧副本；旧 Worker 已停止后新版生命周期失败，则明确报告失败，不自动执行旧版掩盖错误。下一次有效保存或手动重试可以恢复。
