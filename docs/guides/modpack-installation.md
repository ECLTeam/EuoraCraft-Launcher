# 整合包安装与可选文件

## 安装流程

从实例页导入本地 `.zip` / `.mrpack`，或在下载页选择在线整合包版本，进入同一个安装向导。

1. 读取安装信息。本地文件先生成私有快照；在线压缩包先下载再解析。这一步不下载清单引用的模组文件，也不安装基础游戏。
2. 选择可选文件。默认全部选中，可搜索、全选或全不选；必需文件不能取消，客户端不适用的文件自动跳过。没有可选文件的包直接进入确认。
3. 确认安装目录和新实例名称，再开始安装。已存在的实例不会被覆盖。
4. 查看进度与结果。可以收起向导，安装继续执行；完成后从任务面板重新查看结果或打开实例。取消请求以后台操作确认的实际状态为准。

大小提示是选中清单文件的已知大小小计。未知大小单独计数；基础游戏、加载器、整合包压缩包与解压占用不包含在该小计内。

取消选择的文件不会下载，也不会从整合包覆盖目录重新复制进实例。搜索只改变显示内容，不清除搜索结果之外的选择。

## 失败与范围

解析失败可重试，安装目录和实例名会保留。预览只在当前启动器进程有效，空闲 30 分钟后需要重新解析；最多同时持有 4 份准备记录，关闭其他预览后可继续。

安装失败或取消时清理本次临时安装内容，不替换已有实例。基础游戏和加载器可能已经完成安装；这些独立基础版本会保留。

支持范围沿用当前格式解析器：Modrinth、CurseForge、FTB，以及已有的 MCBBS、HMCL、MultiMC 和 ECL 包读取。HMCL 内容仍按当前解析结果重建；MultiMC 自定义 patch 不在支持范围。向导会显示适用的格式限制与警告。MCBBS 的 `force` 表示更新覆盖规则，不能据此将文件视为可选。

本功能不提供整包升级、跨进程恢复安装任务或导出向导。

## 内部接口维护

旧的 `game_instance_import` 和 `game_modpack_online_install` 已移除，调用方统一使用以下命令，无旧字段别名或自动迁移：

| 命令 | 请求 | 结果 |
| --- | --- | --- |
| `game_modpack_prepare` | 本地：`source: local, source_path`；在线：`source: modrinth/curseforge/ftb, project_id, file_id` | `preparationId`、`operationId` |
| `game_modpack_preparation_get` | `preparation_id` | 状态、到期时间、清理状态及就绪时的预览 |
| `game_modpack_preparation_release` | `preparation_id` | 幂等释放；不停止已提交的安装 |
| `game_modpack_install` | `preparation_id, game_path, new_version_id, excluded_file_ids` | 后台安装 `operationId` |

`excluded_file_ids` 必须显式传递。空数组表示安装全部可选文件；集合只能包含同一预览内的 optional 文件标识，重复、未知、必需和不适用项均拒绝。文件标识与下载路径无关，CurseForge 初始同为 `mods/` 的引用也能分别选择。

准备回执不等于解析完成；等待对应操作 completed 后再读取预览。准备和安装使用现有 `game_operation_get`、事件、取消及任务状态模型。安装结果包含 `versionId`、格式、下载数、排除可选数、不适用数、覆盖文件数、基础版本和警告。

准备资源由后端持有；页面关闭或迟到响应必须释放引用。正在准备的记录释放后取消执行，临时目录待执行方退出才删除。安装取得独占所有权，目标目录同时受互斥保护；失败清理有界重试。该状态不持久化为可恢复安装记录。
