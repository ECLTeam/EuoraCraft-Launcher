# 导出整合包

在实例详情的概览操作区点击“导出”，打开全屏设置页。输出格式为标准 `.mrpack`。

填写整合包名称、版本和可选简介。Minecraft 与加载器版本来自源实例，不能在此修改。文件树列出实例实际游戏目录中的可导出内容，支持逐项、目录和分类勾选；搜索只过滤显示，“全选可选项”仍作用于全部可选文件。

推荐选择包含启用模组、配置、脚本、基础游戏设置、资源包与光影。存档、截图和服务器列表默认不选；主动选择后可能包含个人信息，请在分享前确认。日志、运行依赖、缓存、已知账户凭据和其他实例不提供选择。取消必需模组可能使整合包无法正常运行。空选择会生成只包含游戏与加载器依赖的整合包。

资源处理提供两种方式：

- 优先引用在线来源：仅对已选启用模组反查 Modrinth、CurseForge，识别到的文件在导入时下载；未识别或查询失败的文件直接打包，结果中显示警告。
- 直接打包：所选文件全部进入整合包，不进行在线来源反查，输出通常更大。

点击“导出”选择保存位置。取消保存不会创建任务。提交后可以关闭设置页，后台任务继续执行；再次打开同一实例的导出页可查看本次会话中的任务。取消操作先发送请求，以任务实际状态为准。

导出使用预览时确认的文件选择；所选文件或实例元数据发生变化时需要刷新列表。失败或取消保留已有目标文件。不同实例不能同时向同一位置导出。

## 当前接口

`game_instance_export_preview` 接受实例目标，返回扫描操作句柄；完成结果包含 `sourceRevision`、有效隔离状态、依赖及文件清单。每个文件提供服务器生成的 `fileId`、相对路径、分类、大小和推荐状态，不接受客户端指定源文件绝对路径。

`game_instance_export` 除实例目标与 `output_path` 外，必须提供 `pack_format: modrinth`、`source_revision`、`selected_file_ids`、`pack_name`、`pack_version`、`summary` 与 `resource_mode: references | bundled`。不接受旧版无文件选择的请求。名称、版本限 100 字符，简介限 2000 字符，候选清单和选择最多 50000 个文件；扫描超限明确失败，不返回截断清单。

导出操作结果包含 `path`、`format`、`onlineFiles`、`packedFiles`、`selectedBytes` 与 `warnings`。任务提交成功不代表文件已经生成。
