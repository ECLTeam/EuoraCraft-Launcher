# ADR-004：插件配置默认使用宿主设置中心

- 日期：2026-11-08。
- 状态：用户已确认，本地实现与验收完成，未推送或发布。

## 问题与选择

外置联机页原先自行实现节点设置弹窗，与已有插件设置全屏弹窗重复。用户明确要求把默认配置入口作为独立的插件开发约束。

选择复用宿主的插件设置中心，并将其挂载到应用级。当前调用方为插件管理页和 ECL-OnlineGame 联机页；这两个入口共用一个控制状态和原有 `PluginSettingsModal`，不复制配置组件。联机页保留业务操作与打开设置中心的按钮。

## 契约

- 普通持久化配置经 `settings.define` 声明，默认不另做设置页、配置弹窗或保存表单。特殊业务确实不能用标准中心表达时，须先说明并获用户确认。
- Vue 插件代码取得绑定自身的 `SDK`，调用 `SDK.ui.openSettings()` 选中自身配置；不依赖可被其他插件改变的全局 SDK 引用，也不需要离开当前业务页面。
- 插件管理 store 维护设置中心的打开状态及目标，关闭使尚未完成的打开请求失效。仅在设置中心打开时订阅插件状态变化，关闭或卸载解除订阅。
- 多行配置使用通用 `text` 类型，值仍为有界字符串，保留换行并复用原有身份、schema、revision、原子保存和失败反馈。
- 只在值变化后保存；房间码、端口等当次操作参数仍属于业务页面。

约束真源为 [独立插件开发约束](../external_plugins/AGENTS.md)，公开调用方法见[配置指南](guides/plugin-development/settings.md)。这不新增 Worker 权限、不代替用户授权，也不将主窗口脚本注入描述为沙箱。

## 验证

定向前端 46 项、后端 9 项通过；最终前端全量 1327 项通过、1 项 todo，生产构建通过。真实 Windows 启动器中，从联机页打开标准全屏设置中心并选中 ECL-OnlineGame，验证多行实际保存、未变化不增加 revision、关闭仍保留原业务路由、停用清理及兼容插件独立运行。记录位于本地 `output/playwright/onlinegame-ed16e1f3`，未发现初始化或页面错误。6 张宿主视觉基线比较均为零变化；此前样式提交的 8 张基线亦全部通过。
