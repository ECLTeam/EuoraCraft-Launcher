## 3. 页面与交互设计

### 3.1 联机页入口

- 删除现有顶部折叠区及其组件挂载。
- 在联机工作区内容顶部增加紧凑的操作行，右侧放全局 `UiButton` 的轻量齿轮按钮“联机设置”，不用独立的大卡片包装。
- 保留文字和图标，补齐键盘焦点及可访问名称。浅色、深色和图片背景下沿用现有主题规则。
- 点击进入 `/settings/launcher?section=connector`。通过 Vue Router 导航，不使用整页刷新。
- 空闲和活动房间状态均可找到入口；创建、加入、退出等异步操作进行中禁用入口，避免主动跳转打断尚在处理的页面操作。
- 窄窗口和长译文允许操作行换行，避免挤压房间表单。

### 3.2 启动器设置中的“联机”分组

将分组放在下载代理分组之后、开发者分组之前。复用 `SettingSection` 和 `SettingRow`，不增加设置侧栏项目。

```text
联机
节点策略              [ 自动 / 公共与自定义 / 仅自定义 ]
当前策略的简短说明

自定义节点地址        （涉及自定义节点的模式才显示）
[ 每行一个完整节点地址                               ]
示例：tcp://relay.example.com:11010

保存后将在下次创建或加入房间时生效，当前房间不会切换节点。
[错误或保存结果提示]
                                      [恢复默认] [保存]
```

- 自动：使用公共节点，隐藏地址编辑区。
- 公共与自定义：公共节点和填写的自定义节点共同参与连接，沿用后端现有策略。
- 仅自定义：只使用填写的节点，不回退公共节点；至少填写一个有效地址。
- 模式说明随选择更新，不通过长下拉选项承载全部说明。
- 地址编辑区采用独立的纵向布局，避免把多行输入框挤进普通设置项右侧的狭窄控制区；局部样式不改变其他 `SettingRow` 的布局。
- 使用现有 Naive UI 输入/选择控件及项目主题。节点数量、协议、端口、凭据等规则以现有后端校验为准，不增加节点探测或网络诊断功能。

### 3.3 加载、保存与恢复默认

- 配置加载中显示加载状态并禁用编辑；加载失败显示错误与重试入口，禁止保存未成功读取的默认值。
- 用户修改只更新组件草稿。点击保存才调用 `connector_nodes_set`；保存期间禁用编辑、重复保存和恢复默认。
- 保存时按行拆分、去首尾空白、过滤空行，保留后端规范化和去重后的返回值作为最新界面状态。
- 切换为自动模式时隐藏地址，但不立即清空已输入的草稿；在同一页面切回自定义模式可继续编辑。普通保存保留已填写地址，自动模式的后端策略忽略这些地址。
- 保存成功给出简短反馈，并保留下一次连接生效说明；保存失败保留用户输入，显示可读错误，不伪装成功。
- “恢复默认”明确表示立即保存 `{ mode: 'automatic', nodes: [] }`；仅请求成功后替换界面草稿，失败时保留原模式和地址。使用按钮附近说明明确此动作会保存，不新增确认弹窗。
- 保存操作与其他启动器配置使用各自已有 IPC，避免用启动器配置覆盖 connector 分组。
- 离开设置页时，未保存的节点编辑草稿不写入配置。本次不引入跨页面草稿持久化或全局离页确认机制。

### 3.4 跳转与分组定位

- 为联机分组设置稳定定位标记，如 `data-settings-section="connector"`，与显示文案和语言无关。
- 在设置页挂载和查询参数变化时识别 `section=connector`。等待页面渲染和现有进入过渡就绪后，将分组滚动到可见位置；清理等待任务，避免离页后的回调影响新页面。
- 将键盘焦点移到分组标题或容器，使用 `tabindex="-1"`，不自动展开选择器。确保目标聚焦不会造成第二次滚动。
- 重复进入或设置页已挂载时也能定位；普通进入设置不自动滚到联机分组，未知查询参数不触发定位。
- 使用现有滚动容器和减少动态效果规则，不修改全局 Router 的滚动策略，不增加持续闪烁或高亮动画。
- 返回联机页按现有导航行为重新获取后端状态，不调用退房或重新连接。房间码草稿、所选实例和创建步骤按当前普通离页规则重置；本次不增加联机页面缓存。这个取舍是方案 C 切换页面的现有行为边界。

## 7. 风险与处理

- 跳转时机：页面过渡可能导致滚动过早，需在实际桌面确认，不以组件测试的 `nextTick` 结果代替桌面验收。
- 状态恢复：离开联机外壳会停止轮询，必须验证返回后刷新后端状态，不扩大为全局连接生命周期改造。
- 显式保存：与部分现有设置自动保存方式不同，必须让保存按钮、生效说明、恢复默认的保存含义清晰可见。
- 布局：多行地址采用独立局部布局，不为这一项改写所有设置行样式。
- 验证边界：无后端代码变更仍需执行主仓库集成回归；测试环境或实际联网受限时如实记录，不跳过强制检查并提交。
