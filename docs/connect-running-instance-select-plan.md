# 联机创建房间运行实例下拉框实施方案

## 状态与需求

用户已选择方案 B 并确认实施；功能修改、测试、构建和桌面验收已完成。

目标位置：更多 → 联机 → 创建房间 → 运行实例。

- 无运行实例时，下拉框呈禁用样式，显示“暂无运行实例”，点击不能展开。
- 有运行实例且联机服务可用、无进行中的操作时，可以展开并选择实例。
- 展开后直接显示实例列表，不显示搜索框。

## 当前实现与影响分析

- `frontend/src/views/connect/ConnectRoomTab.vue` 使用共享 `UiSelect`，显式传入 `searchable`。
- 当前禁用条件 `createRoomDisabled` 只包含联机服务不可用和操作进行中，未包含运行实例为空。
- `frontend/src/components/ui/Select.vue` 已提供 `disabled` 和 `searchable` 属性；搜索默认关闭，禁用时触发点击不会展开。
- 运行实例来自 `instanceRuntimeApi.list()`，页面订阅运行实例变化并重新读取列表。
- 页面已有无运行实例提示，以及独立的“输入端口”入口。空列表禁用条件应仅加到实例选择器，避免阻断手动端口流程。
- 改动难度低，涉及页面模板、六个语言文件与现有页面测试。前端为独立 Git 子模块。

## 可选方案

| 方案 | 具体行为 | 取舍 |
| --- | --- | --- |
| A | 无实例禁用下拉框，移除搜索框，保留现有占位文案和下方空状态提示 | 满足需求，改动集中，不增加翻译字段 |
| B（用户已选择） | 在 A 基础上，将无实例时占位文案改为“暂无运行实例” | 禁用原因更直接，需要补齐六个语言文件 |

以下步骤按已选方案 B 编写。

## 空状态文案

在 `frontend/src/i18n/locales/` 的六个语言文件中新增 `connect.create.noRunningInstancePlaceholder`，与现有的详细提示 `noRunningInstance` 分开使用。

| 语言文件 | 新增占位文案 |
| --- | --- |
| `zh-CN.json` | 暂无运行实例 |
| `zh-TW.json` | 暫無執行中的實例 |
| `en-US.json` | No running instances |
| `ja-JP.json` | 実行中のインスタンスはありません |
| `de-DE.json` | Keine laufenden Instanzen |
| `ru-RU.json` | Нет запущенных экземпляров |

有运行实例时继续使用 `connect.create.instancePlaceholder`；下方的详细空状态提示保留现有内容。

## 具体改动与实施步骤

1. 检查主仓库和前端子仓库状态，保留已有无关变更。
2. 修改 `ConnectRoomTab.vue` 中 `id="connect-instance"` 的 `UiSelect`：
   - 删除 `searchable` 属性，使用组件默认的关闭搜索行为。
   - 将禁用表达式改为 `createRoomDisabled || !runningInstances.length`。
   - 根据 `runningInstances.length` 切换占位文案：为空时使用 `noRunningInstancePlaceholder`，非空时使用原有 `instancePlaceholder`。
   - 在上表六个语言文件中补齐同名翻译键，不修改其他联机文案。
   - 保留原有实例选项、选择值、提示和手动端口入口逻辑。
3. 在 `ConnectRoomTab.test.ts` 中补充实际交互回归用例：
   - 无运行实例时选择器禁用，显示“暂无运行实例”，点击不展开，详细空状态提示可见。
   - 有运行实例时可展开，列表展示实例且没有搜索输入框，选择实例后仍可进入端口步骤。
   - 运行实例变化为空或重新出现时，禁用状态与占位文案随列表更新；已选实例退出后，空列表仍应显示空状态文案。
   - 检查六个语言的空状态翻译键完整，并验证切换语言后空状态文案同步更新。
   - 无运行实例时仍可进入手动端口步骤；保留服务不可用与忙碌状态的禁用约束。
4. 执行下方验证；测试失败先修复，不提交未通过的功能改动。
5. 验证通过后，在前端子仓库提交本次功能与测试；主仓库仅提交本方案及对应前端指针更新，检查暂存区不混入其他子模块和构建产物。
   - 前端提交示例：`fix: 调整联机运行实例选择器的空状态和搜索行为`。
   - 主仓库提交示例：`fix: 同步联机运行实例选择器调整`。
