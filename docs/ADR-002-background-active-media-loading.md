# ADR-002：背景初始化只加载当前启用媒体

- 日期：2026-11-07
- 状态：已实施。
- 决策依据：用户选择修正本机图片路径并修复背景分支加载的 B 方案。

## 背景

图片与视频各自保留设置，但主题初始化曾先读取图片，再选择媒体分支。未启用图片的失效路径因此产生错误，并可能阻断视频初始化。

## 选项与决策

只重选图片可以修复本机旧路径，但保留未启用资源读取的问题。采用按需加载：先恢复图片与视频设置，再激活当前分支；切回图片时才读取单图或扫描轮播目录。当前真正启用的图片失败仍反馈错误并允许重试。

复用现有主题 store、背景激活方法和设置入口，不新增框架、IPC 或持久化格式。切换代次保护防止迟到结果覆盖新分支，图片源保留原始地址以支持封面与图片之间的切换。

## 影响与验证

视频启动不再依赖未启用图片是否存在，用户的另一个背景分支设置继续保留。共享主题变更按仓库要求完成前端全量检查与构建，另用 Windows 原生验证背景与封面切换。

具体改动、测试、局限与本机重新关联证据见[实施与验收记录](plans/background-inactive-image-loading-2026-11-07.md)，关联 [#130](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/130)。
