## 状态与目标

- 日期：2026-10-03。
- 用户已选择方案 A：对齐式表单，并明确「开始实施」。2026-10-03 完成实现与本地验收。
- 本次是已完成的工具页下载功能的界面修订；原方案记录在 `tools-layout-and-custom-download-options-plan.md`。
- 保留下载主卡铺满内容区、NAT 检测位于下方紧凑横条的结构，改善表单对齐、控件风格和操作层级。

## 现状与问题

`frontend/src/components/connect/CustomDownloadCard.vue` 使用 Naive `NInput`，浏览、请求头增删按钮使用 `UiButton size="sm"`，开始按钮使用默认 `md`。项目的 `UiInput` 与 `UiButton md` 均为 29px，`UiButton lg` 为 36px；当前输入框与小号按钮搭配没有统一的尺寸基准。

表单逐项纵向堆叠。命名方式、名称提示、原生折叠箭头、覆盖选项和开始按钮分别占据独立位置，宽卡片的视觉重心集中在左侧。NAT 使用强调色描边的小号按钮，与主表单的辅助操作也不一致。

本次涉及两个界面组件、工具页专属样式和相关前端测试。业务接口、下载任务状态、会话表单存储及后端下载规则继续沿用现有实现。

### 表单行与尺寸

1. 使用工具页内部的 CSS Grid 建立统一标签列与内容列。标签列初始 96px，内容列 `minmax(0, 1fr)`；列间距 16px、主要行间距 16px，标签使用 13px 字号。
2. 地址、文件夹、自定义文件名、UA 与请求头键值输入统一使用现有 `UiInput`，采用其 29px 高度、主题边框与焦点样式。通过 `id`、`label for` 和 `aria-label` 关联字段名称。
3. 文件夹输入与浏览按钮同高，按钮使用 `UiButton md / secondary`，搭配文件夹图标。长路径在输入框内滚动，按钮保持自然宽度。
4. 命名方式使用现有 Naive `NRadioGroup` 与 `NRadioButton` 组成分段选择，通过局部主题和样式与 29px 表单控件对齐。保留单选语义、键盘切换和选中反馈。
5. 自定义名称输入和提示放在内容列中；原文件名提示也与内容列左边缘对齐。地址为空时显示原文件名解析规则，输入地址后显示预估名称，最终名称仍以下载响应为准。
6. 卡片宽度低于 520px 时改为标签在上、控件在下。长翻译可换行，标签列不承担固定宽度；请求头行在窄窗口按键名、值、删除操作顺序换行。

### 高级设置

1. 保留原生 `details/summary` 的折叠语义与键盘行为，用项目 `UiIcon` 绘制方向箭头，隐藏浏览器默认标记，统一字体、间距、悬停和可见焦点样式。
2. UA 使用与主要字段相同的标签列、输入框及对齐方式。
3. 请求头区域提供清晰的键名、值标签。添加使用 `UiButton md / secondary`，删除使用同尺寸文字按钮并提供明确名称；不使用尺寸过小的强调色描边按钮。
4. 折叠时保留 UA 和请求头值。高级设置内的校验错误应在展开区域内可读，整体错误区继续提示阻止开始的原因。

### 底部操作与任务状态

1. 卡片底部使用分隔线和统一操作栏；左侧是带完整可点击标签的覆盖选项，右侧是开始、取消、重试操作。
2. 开始使用 `UiButton lg / primary`，高度 36px，搭配下载图标；同一区域的取消与重试使用等高辅助按钮。加载、禁用状态沿用现有按钮能力。
3. 使用现有 `NCheckbox`，调整工具页局部样式，使其与项目主题颜色、操作栏基线协调。
4. 进度、任务消息、目标路径与错误置于操作栏上方；长路径和错误可换行。下载中、取消后、失败后、完成后的操作条件及任务轮询逻辑沿用现有行为。
5. 窄窗口允许覆盖选项与按钮组换行，按钮组仍靠内容区右侧对齐，避免遮挡或横向溢出。

### NAT 横条

1. 继续使用一行标题、状态和靠右检测按钮，状态结果较长时自然增高。
2. 检测按钮使用 `UiButton md / secondary`，高度 29px，保留 Wi-Fi 图标、加载状态及禁用条件。
3. 标题、状态与按钮居中对齐，结果、IPv6 提示和错误使用现有主题文字层级。
