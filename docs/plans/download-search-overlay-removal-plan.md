# 下载页搜索遮罩移除与实例导航更名实施方案（已实施）

## 状态与用户选择

- 用户已选择方案 1：仅去掉搜索列表加载时的遮罩背景，保留加载动画、提示文字和原列表。
- 新增要求：下载页导航中的「实例下载」更名为「实例」。
- 用户已于 2026-10-02 明确要求「开始实施」，本方案已完成实施与验收。

## 现状与影响范围

- `frontend/src/views/Download.vue` 将模组、资源包、光影、数据包、整合包和存档六类资源交给同一个 `OnlineModSearch.vue` 渲染。
- 搜索列表使用 `UiLoading` 的 `overlay` 模式，通过 `mods-results-spin` 类设置区域尺寸。
- `frontend/src/styles/components/ui/Loading.css` 为加载层设置 `background: var(--ui-loading-overlay)`，默认值为表面颜色与透明色混合，表面颜色占 72%。这就是列表搜索时的遮罩背景。
- 实例页使用独立的居中加载状态，不需要调整。
- 下载页导航文字来自 `download.instanceDownload`，目前只有 `Download.vue` 引用该键；六种语言各有对应翻译。

## 方案比较

| 方案 | 搜索时的表现 | 取舍 |
| --- | --- | --- |
| 1. 仅去掉背景（已选择） | 原列表继续显示，加载动画和文字继续显示，背景透明 | 改动较小，保留现有搜索状态和列表交互 |
| 2. 对齐实例页加载方式 | 搜索时隐藏原列表，只显示居中加载动画 | 需要调整列表渲染条件，等待时看不到旧结果 |

## 具体改动

### 搜索列表样式

在 `frontend/src/styles/views/OnlineMods.css` 中，针对 `.mods-results-spin.ui-loading` 设置 `--ui-loading-overlay: transparent`。

使用两个类限定选择器，使本页覆盖规则的优先级高于公共组件默认声明，避免依赖样式加载顺序。继续沿用现有 `overlay` 模式、尺寸、指示器定位与加载状态。

此覆盖仅作用于搜索结果区域。资源详情加载层、文件拖入提示层及其他页面继续使用各自已有样式。搜索、分页、筛选、缓存、安装和网络请求逻辑保持现有行为。

### 下载页导航文案

更新六个语言文件中 `download.instanceDownload` 的显示值，保留翻译键和 `instances` 路由值：

| 语言文件 | 新显示值 |
| --- | --- |
| `zh-CN.json` | 实例 |
| `zh-TW.json` | 實例 |
| `en-US.json` | Instances |
| `de-DE.json` | Instanzen |
| `ja-JP.json` | インスタンス |
| `ru-RU.json` | Экземпляры |

更名范围为下载页这一导航项，不扩展到其他页面标题或「实例管理」等文案。
