# Java 管理页面布局调整

用户已审阅截图问题及两种方案，并明确要求“开始调整”。本次采用整页调整方案；基线为主仓库 `b3492a2`、前端 `cae6bd7`。

## 改动范围

- `JavaTab.vue` 与页面样式：移除 820px 最大宽度和自动收缩高度，保留设置页已有外边距，让唯一卡片占满可用区域。卡片正文作为受控容器，工具栏固定，内容区域承担主要滚动。
- `JavaManagerPanel.vue`：运行时按标题、版本及来源、路径、操作分层排列。列表使用分隔线，减少叠加背景和边框，继续使用当前主题、透明度和模糊设置。下载视图及共用该面板的全屏选择窗口一并验证。
- 路径默认单行省略，通过原生 details / summary 点击或键盘展开完整路径，允许选中复制；长路径展开后可换行。
- 保留“设为全局 Java / 使用此 Java”和适用的更新、重新定位入口；启用 / 停用、打开目录、移除安装 / 登记放入现有 Naive UI 下拉菜单。移除继续经过现有确认弹窗，在用或被引用时不可执行；系统发现的条目不提供移除入口。
- 工具栏与运行时操作使用统一小号尺寸，宽度不足时正常换行。新增可访问名称同步六种语言。

局部调整列表行的方案改动较少，但无法解决单卡片高度及整体留白问题，因此按已确认的整页方案实施。后端 Java 安装、配置格式与生命周期不变。

1. 先补充菜单操作、禁用条件及路径展开的行为回归，在原实现上确认失败。
