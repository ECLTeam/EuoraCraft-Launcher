# 主按钮文字与加载动画可见性实施方案

关联问题：[ECLTeam/EuoraCraft-Launcher#92](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/92)

## 目标与范围

- 实色主按钮统一使用白色文字和图标；当背景与白色的对比度不足时，仅加深按钮背景，保持主题色相近。
- 主按钮的加载动画与文字一样清晰可见，同时保留其他按钮变体在各自背景上的可读性。
- 覆盖公共 `UiButton`、Naive UI 实色主按钮及使用实色主按钮样式的相关页面；保留用户选择的主题色及其他组件的主题语义。
- 已有截图中的紫色是验收样例；用户选色、背景取色及 Monet 色阶均需考虑。此方案不改变主题配置或持久化格式。

## 当前情况

- `frontend/src/composables/useTheme.ts` 的 `textOnColor` 根据对比度在黑白间选择前景色；公共 CSS 变量 `--text-on-primary` 和 Naive UI 的主按钮文字覆盖均使用该规则。
- `frontend/src/styles/components/ui/Button.css` 的主按钮使用 `--primary` 背景及 `--text-on-primary` 前景；悬停、按下使用另两级背景。该变量也被其他界面及危险按钮引用，不能直接全局改成白色。
- `frontend/src/components/ui/Button.vue` 加载时使用 `UiLoading`。后者在 `frontend/src/styles/components/ui/Loading.css` 为自身设置强调色，导致颜色不会自动继承按钮文字，且可能与主按钮背景重合。
- Naive UI 和其他使用主题变量的界面也可能受影响；实施时先确认实际组件及样式调用，避免把文字按钮、边框按钮或危险按钮错误套用实色主按钮颜色。

## 具体改动

1. 在现有主题计算中为实色主按钮生成专属的普通、悬停和按下背景色；以白色正文至少 4.5:1 的对比度为目标，背景不达标时逐步混入黑色，选择满足阈值的最小调整。对输出色取整后的最终结果重新验证对比度。分别处理普通、悬停和按下色，确保状态仍可辨认；焦点状态与实际背景一致。
2. 在主题层提供按钮专用的颜色变量，并在 `UiButton` 的 primary 变体使用它们和白色前景；为 Naive UI 实色 primary 按钮配置对应的背景、边框及普通、悬停、按下和焦点文字色。核对 Naive UI 的 text、ghost 等变体，避免误将白字或实色背景应用于非实色按钮。
3. 清查其他直接使用 `--primary` 与 `--text-on-primary` 构成的实色主按钮，按实际语义使用同一套按钮专用颜色；不改变用于普通强调色、其他组件和危险色的全局变量。危险按钮根据自身背景单独处理文字与加载动画，不能依赖主题主色的前景色。
4. 在按钮上下文中让 `UiLoading` 的圆弧及轨道使用当前按钮前景色及合适透明度，覆盖各按钮变体；不改变独立加载组件的默认强调色。检查 scoped CSS 的实际作用域和变量覆盖优先级，确保加载动画真正生效。
5. 为主题色计算、主按钮状态和加载动画补充行为回归测试，包括截图相近的紫色、深色、浅色、白色和普通主题色，以及明暗和 Monet 色阶。对颜色变化测试对比度及非按钮主题色保持原值；对其他按钮变体验证颜色与加载状态。缺陷回归须先在修复前失败、修复后通过。

## 实施步骤

1. 复核前端子仓库规范、当前工作区与按钮调用，确认 Naive UI 所用版本的主题字段及所有实色主按钮入口。
2. 先编写并运行有代表性的失败回归测试，记录失败原因；实现按钮专用色阶及主题覆盖，再修复按钮内加载动画。
3. 清查相同问题的直接调用方，调整必要样式，并核对危险、次要、描边及文字按钮的加载状态。
4. 按下列计划执行检查与真实界面验收，记录实际结果及未覆盖项；保留现有无关工作区修改。

## 测试与验收

- 此项涉及公共组件和主题系统，按主仓库规范 6.1、6.2 对前端执行 `pnpm check`、`pnpm build`；缺陷回归测试需展示修复前失败、修复后通过。
- 启动实际启动器，在 Classic / Folia 的亮暗主题、相关背景、透明度及模糊设置下检查；覆盖默认、最小允许及放大窗口。检查普通、悬停、按下、焦点、禁用和加载状态，确认文字、图标、动画、边框及焦点可辨。
- 使用截图中相近的紫色、较浅和较深主题色核对按钮，测量正常文字与实际按钮背景的对比度至少 4.5:1；检查加载圆弧、图标的非文本对比度至少 3:1。禁用控件按适用准则和视觉可辨性验收。
- 同时检查 `UiButton` 和 Naive UI 主按钮、受影响页面与危险/描边/次要按钮，确认用户选定的主题色在其他界面仍生效；确认加载状态阻止重复点击并在结束后恢复。
- 对实际未能完成的启动器、主题或平台验收如实报告，不以自动测试替代真实界面验收。完成后依规范总结实际验证和影响范围。
