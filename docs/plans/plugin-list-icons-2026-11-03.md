# 插件列表图标与间距调整

## 需求与实施范围

用户明确要求为插件设置全屏弹窗的插件列表补上图标，并放大外部列表图标、去掉外框，
将后方信息合理右移。本次按该指令直接实施，保留其他工作区改动。
关联 [#111](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/111)。

当前设置列表只显示名称；外部列表为 16px 图形加 28px 带框表面。
两处均沿用插件现有 `icon` 标识及 `UiIcon`，没有图标时显示默认插件图形。

## 具体调整

1. 设置列表在名称前加入 22px 图标，保留按钮选中、悬停、焦点与长名称提示。
2. 外部列表采用 40px 无框图标，固定其收缩行为，名称间距使用现有主题变量。
3. 表头与列表行使用相同列宽及间距；适当收紧右侧列预留，将版本、状态、操作向右排列，
   把更多宽度留给名称。图标与文字保持垂直居中。
4. 也考虑只放大至 32px，但本次选择 40px，使图标明显放大，仍适合现有约 60px 的列表行。
5. 不改变插件图标协议、权限、设置读写、公共图标组件或全局主题。

## 验证

本次为两个业务组件的局部图标和视觉模板调整。执行修改文件的格式与 ESLint 检查、
类型检查、设计检查和构建；仅运行直接相关的现有页面及设置组件用例。
在真实浏览器的实际 showcase 页面查看 Classic/Folia 亮暗主题、最小/默认/放大窗口，
以及自定义图标、默认图标、长名称、筛选与列表末项可达性。
使用背景、透明度与模糊代表状态；无需原生启动器验收或无关全量测试。

## 结果

- 修改的三个生产文件均通过 Prettier、ESLint（Vue）、设计检查和 `git diff --check`。
- `pnpm build` 含类型检查并通过；构建保留已有的大分块提示。
- `Plugins.test.ts` 和 `PluginSettingsModal.test.ts` 的现有定向用例通过。
  本次为视觉调整，不新增机械镜像断言，不运行无关全量测试。
- 真实 Edge 浏览器使用实际 showcase 页面及内存中的合成插件数据：两处列表覆盖
  Classic/Folia × 亮暗 × 960×600、1200×800、1440×1000，共 24 个界面状态；
  外部图标 40px、边框 0px，设置图标 22px、列表按钮高度 36px，表头与数据列一致。
- 查看了默认和自定义图标、长名称截断及完整提示、筛选/清空、选择/切换和列表末项滚动。
  德语最小窗口没有水平溢出；图片背景、70% 表面透明度及模糊代表状态下两处图标正常显示。
  未发现图标挤压、文字遮挡或操作列溢出。仅进行浏览器验收，没有启动原生启动器。
- 原始记录与截图保存于 `output/playwright/plugin-list-icons/`，
  最终预览为 `plugins-final.png` 和 `settings-final.png`。
