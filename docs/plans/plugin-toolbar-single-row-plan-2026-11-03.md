# 插件列表顶部单行工具栏实施方案

日期：2026-11-03。状态：用户已选择方案 A，等待本文的实施确认。

关联问题：[#107 插件列表顶部工具栏改为单行并精简操作按钮](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/107)。

## 1. 需求与方案选择

用户反馈插件列表顶部占用两行、按钮文字较多，希望改为一栏并将部分按钮改为图标。

已提供两个方案：A 保留文字筛选及图标加文字的安装按钮，仅设置改为图标；B 将安装也改为纯加号。用户选择 **A**。

目标排列为：

```text
[搜索插件……                ] [全部｜已启用｜已禁用] [齿轮] [+ 安装插件]
```

本轮只调整列表顶部，不改列表行内的权限、启停、重载、卸载按钮，也不修改全屏设置内部布局或插件开发模式启动契约。

## 2. 当前情况与影响范围

调查基线：主仓库 `4f1f0db954e88b68fdf7c242806f45a7f565cd16`，前端 `558b15a21e1404f79651301db96a7cc8e5ccafbe`。

当前 `Plugins.css` 将 `.plugins-search` 指定为跨全部列，使搜索独占一行，筛选及操作排到第二行。设置是文字按钮；安装按钮使用已有下拉菜单，支持归档及目录安装。Classic 使用单选按钮组，Folia 使用分段标签。

| 文件                                    | 具体改动                                                                                                                                                 |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `frontend/src/views/Plugins.vue`        | 将统一设置入口改为齿轮图标按钮，保留打开同一设置界面的事件；添加复用现有国际化键的提示和可访问名称；搜索框补齐可访问名称。安装保留加号、文字及下拉行为。 |
| `frontend/src/styles/views/Plugins.css` | 移除搜索跨列，使用搜索自适应、筛选和操作按内容占宽的单行布局；操作区不换行，控件垂直居中；间距、控件尺寸沿用当前项目变量。                               |
| `frontend/src/views/Plugins.test.ts`    | 更新设置按钮定位方式，覆盖图标入口的名称、设置打开、搜索、筛选和安装菜单行为。                                                                           |
| 主仓库相关原生验收脚本                  | 补充受影响工具栏的真实几何断言和交互检查；可复用现有启动器验收设施，避免重跑无关热重载全流程。                                                           |

已有 `settings`、`add`、`search` 图标可直接复用。提示和可访问名称使用现有 `plugins.settingsCenter`、`plugins.searchPlugins` 等六语言键，无需新增文案或依赖。

已有 `frontend/MAPPING_TABLE.yaml` 删除及 `output/` 中其他任务文件不纳入提交，不覆盖或清理。

## 3. 布局与交互约束

1. 搜索框占剩余宽度，可随窗口缩放；筛选与右侧操作保留完整可操作区域，不因搜索的固有宽度挤出容器。
2. 在项目支持的 960×600 最小窗口、默认及放大窗口内保持单行，不通过隐藏控件、裁切文字或横向滚动掩盖溢出。
3. 保留 Classic / Folia 的既有筛选控件和已选状态；不改搜索与筛选的数据逻辑。
4. 设置使用与当前小控件等高的方形圆角齿轮按钮；悬停可知其为“插件设置”，屏幕阅读器及按名称定位的测试能识别该入口，键盘焦点清楚。
5. 安装继续显示“加号 + 安装插件”并打开原有下拉菜单，归档、目录两种入口保持可达。
6. 设置仍通过原弹窗机制处理进入焦点、关闭及返回焦点；不因图标化新增另一套设置入口。
7. 六语言筛选和安装文字完整显示，搜索占位文字可随输入框宽度自然适配；实际输入、清空及键盘操作不受影响。
8. 不新增颜色字面量、全局样式、公共组件包装、固定页面宽度或业务状态。
