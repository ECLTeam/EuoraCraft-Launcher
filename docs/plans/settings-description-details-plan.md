# 设置说明精简与详情入口实施方案

状态：用户已选择方案二；本文供实施前审阅，尚未修改功能代码。

## 1. 目标与调研基线

设置页默认只展示帮助用户决定如何配置的简短说明。复杂项通过标题旁的帮助按钮查看完整规则，减少常驻文字，同时保留重要限制和操作后果。

调研基于主仓库 `30a7fef` 与其记录的前端提交 `1ac523fa05ece3f77eb55dc4e04a806b05afc77d`。本工作树的前端尚未初始化，读取日常工作区中相同提交的代码进行核对，没有修改该工作区。

当前情况：

- `SettingRow.vue` 只有 `label` 与可选 `description`，所有说明直接显示在标题下。
- 启动器页的代理、重试与证书设置，以及游戏页的命令、环境变量等包含多条规则。
- 外观页同时存在简短说明、实现细节和硬编码中文，需随本次涉及的行统一整理。
- 项目已有 Naive UI `NPopover`、按钮与帮助图标，可以直接复用。
- 实例详情也使用 `SettingRow`，其继承值是配置状态，不能因为文字长便当作帮助说明隐藏。

## 2. 已选方案与取舍

用户选择“短说明 + 详情入口”。相比仅修改文字，需要增加少量帮助交互及验证，但能保留复杂配置的完整使用规则。

分类由文案含义决定，不按字符数自动截断：

1. 标题和控件足以表达含义：移除重复介绍，不添加帮助按钮。
2. 一句话可以说清：精简现有说明，不添加帮助按钮。
3. 包含语法、示例、多项限制或优先级规则：保留短说明，增加详情入口。

“重启后生效”、失败会阻止启动、退出后缺少崩溃检测等重要后果保留在常驻说明中。证书校验关闭的安全影响也须直接可见。短说明允许自然换行，不使用省略号、行数裁切或缩小字号来压缩内容。

## 3. 帮助入口与组件改动

在 `frontend/src/features/settings/components/SettingRow.vue` 增加可选 `details?: string`。当前调用者是设置中的启动器、游戏和外观三个页面，解决同一设置行需要区分摘要和完整规则的问题；不引入独立说明注册表、配置模型或后端字段。

- 仅在有 `details` 时于标题后显示一个低强调的帮助图标按钮，使用现有图标和按钮样式；没有详情的行不预留空位。
- 点击按钮展开 `NPopover`，再次点击或点击外部关闭；采用点击触发，正文可选择、可复制。默认不增加鼠标悬停弹出行为。
- 按钮可通过 Tab 聚焦，Enter / Space 打开，Esc 关闭；Esc 关闭后焦点回到按钮。展开不抢走当前输入控件的内容或触发设置保存。
- 使用国际化的“查看「{label}」的详细说明”可访问名称；展开状态与内容关联可供辅助技术识别。
- 弹出内容使用纯文本和保留换行的样式，不渲染 HTML。需要分段的内容使用完整国际化文案，不拼接句子。
- 复用项目的 Naive UI 主题配置、弹出挂载位置及层级约定。正文用现有字号、颜色和间距，长参数可换行。
- 优先在按钮下方展开并允许组件调整位置；宽度受视口约束，长说明受视口高度约束并可滚动，不遮住后就无法关闭。
- 切换设置页或卸载设置行时关闭并销毁对应弹出内容。

原有 `label`、`description` 和默认控件插槽继续用于当前正常场景，不改变保存、校验或配置继承流程。

## 4. 文案整理范围

下表为中文措辞和信息分配基准。实施时核对现有业务行为，不改变规则来适应文案；保留现有插值和参数示例的实际含义。

| 配置 | 常驻说明示例 | 详情保留的信息 |
| --- | --- | --- |
| 启动器代理 | 用于登录和获取元数据，重启后生效 | 请求范围、自定义模式需填写地址 |
| 下载代理 | 用于游戏与资源下载，重启后生效 | 覆盖的资源类型、与启动器代理独立、自定义地址要求 |
| 自定义代理地址 | 须包含协议前缀 | 使用输入框现有占位示例，不为重复示例单独增加帮助入口 |
| 请求超时 | 单次请求的最长等待时间，重启后生效 | 秒数范围可由控件表达；无额外规则时不加详情 |
| 失败重试次数 | 可重试请求的额外尝试次数，重启后生效 | 适用请求、网络错误、限流及临时服务错误；0 表示不额外重试 |
| 关闭 SSL 证书校验 | 降低连接安全性；微软登录需重启后生效 | 全局作用范围及共享请求即时生效的差别 |
| 下载源、模组源 | 精简为来源选择及直接影响 | 有备用地址时的下载回退规则；MCIM 与 CurseForge API Key 的关系 |
| 日志级别 | 设置日志最低输出级别，即时生效 | 与调试模式相互独立；无需为这一句话增加详情入口 |
| JVM 参数、游戏参数 | 分别说明追加到 JVM 参数前、游戏参数后 | 含空格参数的引号规则与现有示例 |
| 启动前执行命令 | 失败或总耗时超过 60 秒时取消启动 | 在游戏目录执行，每行一条并按顺序执行 |
| 启动命令包装器 | 使用外部程序启动 Java | 完整启动命令占位符、未写占位符时的前缀规则与示例 |
| 退出后执行命令 | 游戏退出后执行，失败仅记录日志 | 无论退出码均执行、每行一条，不影响启动结果与崩溃分析 |
| 自定义环境变量 | 每行一条 KEY=VALUE | 空行规则、覆盖系统同名变量、插件变量的覆盖优先级 |
| 游戏窗口标题 | 自定义游戏标题，留空不修改 | instance、version、account 的实际占位符写法及示例 |
| 启动时启动器行为 | 退出启动器后将停止本次崩溃检测与统计 | 游戏启动成功后处理窗口的时机 |
| 锁定内存、进程优先级、高性能显卡、java.exe | 用一句话准确说明实际作用或平台限制 | 不添加无必要的说明入口，不承诺一定改善性能 |
| 背景模式 | 选择背景图片的显示方式 | 单图、轮播、随机模式支持的实际来源 |
| 背景视频 | 仅支持本地 MP4 或 WebM | 删除对内部流加载实现的介绍，无需新增详情 |
| 额外毛玻璃、背景模糊、背景取色 | 精简作用说明 | 保留设置之间的影响边界；取色的恢复方式按需放入详情 |
| 定时切换 | 仅在“跟随系统”模式下生效 | 时间窗口内如何覆盖系统偏好 |
| 语言、字体、圆角等简单项 | 删除重复标题的介绍，必要时保留作用范围 | 不添加详情入口 |

审查三个设置页面中所有现有说明，按上述规则决定精简、删除或拆分。上述表格没有列出的简单项不机械增加详情。

涉及的外观页硬编码标签与说明同步迁入国际化，包括亮暗模式、卡片圆角、控件圆角、对话框圆角及定时切换；与本次无关的其他页面文案不扩展处理。六种语言使用同一套新键和信息分配，修改已有摘要，按需增加 `…Details` 键，清理不再使用的说明键。格式示例中花括号须按 vue-i18n 规则转义。

实例详情本次保持原有继承状态展示，不批量隐藏长配置值；验证共享组件新增功能不会影响该页。Java 管理、关于、联机节点组件及插件自有设置不扩展增加说明。
