# CI 与积压问题修复方案

2026-11-07。五项本地修复与 Windows 验收已完成，待本轮远端推送授权及 Linux CI 验收。主仓库基线 `a2d0e5d`，前端基线 `0c68f50`。

## 第一批 · 恢复可验证的 CI

1. **LittleSkin 回调测试**。Linux CI 在关闭旧回调后使用裸 socket 重新绑定原端口，报 `EADDRINUSE`。将测试改为关闭后创建新的 `LittleSkinCallback`，通过生产入口在同一地址启动，并完成一次有效请求。保留原有错误 state、Host、路径和重放断言，以及真正被监听器占用时拒绝启动的用例。在 Linux 先复现旧断言，再验证新旧回调可以依次运行，Windows 执行同组用例。如果生产入口也无法重启，继续定位连接和监听器生命周期，再按账户认证与平台边界扩大验证。 [#126](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/126) · [失败日志](https://github.com/ECLTeam/EuoraCraft-Launcher/actions/runs/42331958586/job/128280273997)
2. **插件权限扫描**。让浏览器测试的模拟插件同时声明 `installation_id` 和与模拟权限详情一致的 `requested_permissions`，用真实页面打开正确的插件权限弹窗。验证声明权限的插件可进入弹窗、无额外权限的插件仍直接启用。补齐入口的定位断言，保留全部 31 个扫描场景。 [#110](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/110) · [失败日志](https://github.com/ECLTeam/EuoraCraft-Launcher/actions/runs/42331958525/job/128280274274)
3. **可访问性报告与例外**。扫描完整后，用原始报告与 `docs/governance/exceptions.json` 逐项对照。修复确认的界面违规，移除失配记录。已有人工复核的替代定位需核对同一控件与证据，新未决项需逐项复核并保留场景、截图或测量依据。新增或延长期限的例外按项目治理规则单独审查。主仓库和前端独立 CI 最终使用同一份已核对的治理规则与例外。 [#100](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/100) · [工程治理](../governance/README.md)

## 第二批 · 修复可独立验收的功能

4. **声明式面板示例**。将 `examples/plugins/worker_panel/main.py` 中分组的 `children` 和列表的 `columns` 改为 JSON 数组。保持宿主协议对嵌套值的现有校验。在隔离目录使用仓库原样示例，通过真实 Worker 安装、审阅、启用，读取面板和列表，并点击问候按钮验证命令和结果。增加能在旧示例失败的定向回归，验证完成后关闭 Worker。 [#101](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/101)
5. **衣柜三维预览**。以现有底部左侧动画组和右侧旋转组为样式基准。在 `SkinViewer3D.vue` 中用同一个底部布局管理两组按钮，空间充足时左右对齐，空间不足时按组换行。动画组内部可换行，让长译文及开启鞘翅后出现的额外动画仍可见。保留现有控件、旋转和动画行为，为图标按钮沿用现有翻译作为可访问名称。用真实浏览器验证 960×600 德语复现、六语言最小窗口、默认及放大窗口，覆盖 Classic / Folia、亮暗、代表性背景、鞘翅、键盘焦点和点击可达。 [#124](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/124)
