# 实例管理顶部工具栏优化实施方案

状态：用户已选择方案 A 并确认实施；已完成实现、检查、桌面验收和前端提交。

## 需求与现状

用户已认可紧凑列表，接下来优化列表与卡片共用的顶部工具栏，减少平铺按钮，同时保留常用操作和清晰的筛选状态。

当前 `InstalledInstanceList.vue` 顶部包含 9 个按钮、2 个下拉框及搜索框，收藏、置顶、隐藏、分类管理和排序方向分别占据位置，各按钮视觉权重接近。窗口不超过 1050px 时分类与排序下拉框被直接隐藏，入口无法使用。当前工具栏最小高度为 48px。

已讨论方案：

| 方案 | 设计 | 取舍 |
| --- | --- | --- |
| A（已选择） | 合并为筛选与排序，保留搜索、视图切换、刷新、安装 | 常用功能仍易找到，减少按钮数量，筛选与排序各增加一次打开菜单的操作 |
| B | 筛选、排序、视图合并进显示选项 | 顶部最简洁，但调整显示需要更深的操作路径 |

## 选定布局与行为

```text
默认路径  6/6    [搜索实例…]  [筛选·2] [排序] [卡片/列表] [刷新] [安装]
```

### 顶部布局

- 保持单行和原有约 48px 高度；左侧显示路径名称与实例数量，右侧按搜索、筛选、排序、视图切换、刷新、安装排列。
- 搜索框采用可伸缩宽度和简短「搜索实例…」占位符，仍搜索别名、描述、标签、版本与加载器；完整搜索范围通过提示或可访问说明保留。
- 筛选和排序在常用宽度显示图标与短文字，降低连续无文字图标的识别负担。
- 视图切换保留现有卡片/列表双按钮与当前选中态。刷新采用轻量图标样式，扫描中继续禁用；安装使用全局主按钮的小尺寸，文案缩短为「安装」。
- 使用全局按钮、圆角、颜色、边框、弹层及动画约定，避免新增局部主题配置。

### 筛选菜单

1. 将「只看收藏」「只看置顶」「显示隐藏实例」收进同一弹层，使用可辨识的多选状态，选择立即生效，菜单保持打开，方便组合条件。
2. 分类使用单选列表，包含「全部分类」与已有分类；较多分类时区域可滚动。避免再嵌套带搜索框的下拉菜单。
3. 原有「管理分类」放在菜单底部。打开管理弹窗前关闭筛选弹层，继续使用现有分类管理组件与更新事件。
4. 底部提供「清除筛选」，一次重置收藏、置顶、显示隐藏和分类选择，不清空单独的搜索输入，也不改变排序与视图。
5. 顶部筛选按钮显示已启用条件数量：收藏、置顶、显示隐藏各计 1 个，指定分类计 1 个；搜索不计入。数量为 0 时无数字、无激活强调，为 1–4 时高亮并显示数量。
6. 收藏与置顶组合继续按现有交集逻辑过滤；显示隐藏延续现有含义，增加隐藏实例的可见性。

### 排序菜单

- 保留最近启动、累计时长、启动次数、名称、游戏版本五项，显示当前单选项。
- 将升序/降序放在同一菜单内并明确标记当前方向。顶部排序按钮悬停可查看当前方式与方向。
- 使用原 `sortKey`、`sortDirection`、`persistDisplaySettings()` 与实例排序函数，继续持久化排序和视图设置。筛选条件仍保持当前页面状态，不增加新的持久化字段。
- 筛选和排序弹层互斥；点击外部或按 Escape 关闭。弹层大小受视口限制，不增加页面高度，不遮挡原实例操作弹层的关闭行为。

### 窄窗口与可访问性

- 在应用最小尺寸 820×600、常用 960×600 和更宽窗口下验证；所有功能入口始终可用，不再通过隐藏分类或排序功能来节省宽度。
- 窄内容区优先收缩路径名称、数量显示与搜索宽度；必要时筛选、排序、安装仅显示图标，保留文字提示、可访问名称以及筛选数量。视图与刷新入口保持可见。
- 路径长名称省略并保留完整提示。按钮具备键盘焦点、弹层展开状态、选中状态及可访问名称；菜单控制可以通过键盘操作。

## 风险与处理

- 筛选条件收纳后可能被忘记：始终显示有效条件计数与高亮，并提供清除入口。
- 弹层较多时可能发生状态冲突：筛选和排序使用独立于实例更多菜单的状态，打开管理弹窗前关闭工具弹层。
- 多分类与长译文可能溢出：控制弹层宽度和分类滚动区域，窄窗口保留图标入口与完整提示。
- 提取样式可能影响卡片按钮：限定工具栏样式范围，并保留、验证原卡片共享选择器。
