# LittleSkin 云端衣柜布局对齐方案

2026-11-07。已选方案 A，待审阅实施。关联 [#123](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/123)。

## 对照基准与目标

以 [本地衣柜](../../frontend/src/features/accounts/components/WardrobeModal.vue) 的本地皮肤、披风和官方披风页为基准。[LittleSkin 云端面板](../../frontend/src/features/accounts/components/LittleSkinClosetPanel.vue) 当前单独定义网格、文字卡片和工具栏。切换到云端时，卡片列宽、选中样式、预览入口和操作位置随之改变。

- 保留「LittleSkin 云端」入口。云端皮肤、披风使用同一行紧凑工具栏，分类在左，刷新、下载当前材质和重置皮肤或移除披风在右。Classic 沿用按钮组，Folia 沿用分段控件。图标按钮使用现有图标、提示和本地化可访问名称，窄内容区允许换行。
- 云端沿用原衣柜的网格、卡片尺寸、缩略图位置、名称与选中样式。点击卡片或使用键盘选中后更新右侧三维预览。穿戴和下载到本地衣柜使用卡片右下角的图标操作，保留已穿戴标识。长名称按卡片宽度截断，并可查看全名。
- 分页放在左侧列表下方，列表独立滚动。保留加载、空列表、失败重试和补充授权状态，单个缩略图失败使用与原衣柜一致的占位。

## 实施步骤

1. 从 `WardrobeModal.vue` 提取账户功能内复用的衣柜卡片和网格布局。卡片共用缩略图、标题、选中反馈和操作区，调用方提供标识、说明及操作。原有本地皮肤、本地披风和官方披风先接入，逐项对照原有外观和操作。
2. `LittleSkinClosetPanel.vue` 接入相同网格与卡片，合并云端工具栏，并把分页移至独立滚动区域下方。沿用现有的账户、类别、分页、授权与操作禁用状态，复用现有六语言文案。
3. 通过现有 `fetchTextureDataUrl` 缓存与去重链路，按当前页限并发读取缩略图。账户、类别或分页切换时清除页面缩略图状态，关闭衣柜后停止调度新请求，迟到结果仅在原上下文有效时应用。缩略图请求使用独立的失效范围，避免打断右侧预览或穿戴、下载操作。继续使用已校验的云端材质哈希和当前的材质地址。
4. 按下列范围验收。通过后先提交前端，再提交主仓库指针，提交关联 #123。

## 测试与验收

- 按 [项目规范第 6 节](../../AGENTS.md#6-测试与验收) 做前端定向验证。执行改动文件的 Prettier、ESLint、`pnpm check:design`、`pnpm typecheck`、`pnpm build`，以及 `WardrobeModal`、`WardrobeModal.requests` 和 `LittleSkinClosetPanel` 相关 Vitest 用例。卡片复用限于衣柜，覆盖直接消费方。
- 补充定向回归，验证账户、类别或分页切换后旧缩略图不会覆盖当前卡片，单张图加载失败仍可选择、穿戴和下载，键盘选择与图标操作各自触发对应行为。核对现有防重入、授权、穿戴和下载流程。
- 使用本地 Showcase 和模拟材质，在真实浏览器内并排记录同主题、同尺寸下的本地与云端对照截图。覆盖 Classic / Folia、亮暗主题、960×600、默认和放大窗口，以及背景、透明度、模糊的代表组合。确认工具栏对齐、长名称和长译文、列表末项可达、分页、已穿戴标识、焦点、加载、空列表、失败与补充授权状态。
