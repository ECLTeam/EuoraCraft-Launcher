# 截图与服务器页标题栏样式统一实施方案

状态：用户已选择方案 1 并确认开始，代码调整、完整检查、构建和实际 Windows 启动器验证均已完成。

## 需求与现状

目标是让实例设置全屏弹窗中的截图页、服务器页采用原理图页以及已调整的存档页的标题栏风格。

- `InstanceScreenshotsTab.vue` 的刷新和打开截图目录仍是默认尺寸文字按钮，搜索和排序控件也没有设置小号尺寸。
- `InstanceServersTab.vue` 已有刷新列表、刷新状态的圆形图标按钮，以及蓝色添加服务器按钮，但没有指定小号尺寸，主操作额外间距为 4px。
- 两页标题栏缺少参照页的 12px/16px 内边距、底部分隔线与自然换行规则；目前由整个面板提供 12px 内边距。
- 现有 `refresh`、`folder-open`、`wifi`、`plus` 图标均已注册，不需要新增图标资源。

## 方案选择

| 方案 | 修改范围 | 权衡 |
| --- | --- | --- |
| 1：完整统一两个标题栏，已选定 | 图标、控件尺寸、按钮间距、标题栏内边距与分隔线 | 与用户选定的第一张图更一致；需要将原有内容区内边距移至内容容器。 |
| 2：仅统一按钮和控件 | 截图按钮改图标，两页控件改小号，服务器主按钮间距统一 | 改动较小；标题栏内边距、分隔线仍与原理图/存档页不同。 |

下文为用户已选定的方案 1 的具体实施内容，方案 2 仅保留作比较记录。

## 具体改动

1. 截图页搜索框、排序框采用 `size="small"`；刷新与打开截图目录使用 `quaternary circle size="small"`，分别使用 16px 的 `refresh` 与 `folder-open` 图标。
2. 截图页操作集中在右侧，间距 8px。两项均属于辅助操作，保持圆形图标按钮，无需增加新的主操作。
3. 服务器页搜索框、刷新列表、刷新状态和添加服务器按钮统一为 `size="small"`。保留 16px 的刷新/Wi-Fi 图标，以及蓝色“添加服务器”按钮的 13px 加号图标和可见文字。
4. 服务器主操作按钮额外左间距由 4px 调整为 12px，与原理图/存档页一致。
5. 两页辅助按钮保留现有 `loading`、事件和悬停提示，补充对应 `aria-label`；添加服务器保留明确的可访问名称。
6. 两页标题栏采用 `flex-shrink: 0`、居中对齐、8px 间距、自然换行、12px/16px 内边距及底部分隔线。搜索框保留弹性宽度并设置 180px 最小宽度，操作组保持整体换行。
7. 从面板移除原有整体内边距，将 12px 内容内边距移到加载组件内部的内容容器；截图日期分组保留 12px 间距，服务器列表内部保留现有 8px 间距。空状态同样保留内容区内边距。

仅修改这两个页面的标题栏及必要的内容容器布局；截图卡片、服务器条目、编辑弹窗、排序、文件操作、查询状态和连接逻辑保持原行为。不修改后端或用户实例数据。
