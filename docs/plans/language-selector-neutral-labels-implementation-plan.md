# 语言选择器仅显示名称实施方案

## 需求与现状

- 语言下拉框及当前选中值只显示语言名称，移除旗帜和名称前的文字缩写。
- 变更前 `frontend/src/i18n/index.ts` 的六个语言条目包含 `shortLabel`；`frontend/src/views/settings/LauncherTab.vue` 将它与 `name` 拼成选项标签。
- 语言设置持久化的是 `zh-CN`、`zh-TW` 等代码，显示文字与保存值分离。浏览器展示模式和桌面模式共用该选项列表。

## 方案比较与选择

| 方案 | 显示示例 | 取舍 |
| --- | --- | --- |
| A. 仅显示名称（用户最终选择） | `简体中文`、`繁體中文`、`English` | 最简洁，不依赖任何标记或系统 emoji 字体。 |
| B. 名称前加文字缩写（先前方案） | `简  简体中文`、`繁  繁體中文`、`EN  English` | 可快速识别，但增加了用户希望移除的前缀。 |

## 改动分析与实施步骤

1. 从 `supportedLocales` 中删除仅用于显示的 `shortLabel` 字段，保留六个语言代码及名称。
2. 让设置页的语言选项直接使用 `language.name`，选中值与下拉项使用同一名称。
3. 检索前端对 `shortLabel` 和旗帜的引用，确认没有遗漏的显示路径或类型依赖。
4. 运行 `pnpm check`、`pnpm build`；用隔离数据目录启动桌面版，检查当前值与六个选项，并切换一种语言确认保存功能。
5. 检查变更范围，提交前端改动及主仓库文档和子模块指针。

## 验收标准

- 六个语言选项及当前选中值均只显示语言名称，无旗帜或文字缩写。
- 简体中文和繁体中文仍可区分；语言代码、切换和保存逻辑保持现有行为。
- 桌面模式与浏览器展示模式使用同一选项数据。

## 实施与验证记录

- 已从六个语言条目移除 `shortLabel`，下拉选项直接使用语言名称；语言代码及保存逻辑未变。
- `pnpm check` 通过：91 个测试文件通过，378 个测试通过，1 个待办；`pnpm build` 通过。
- 使用隔离数据目录启动桌面版：当前值与六个下拉选项均只显示语言名称；切换为 English 后界面立即更新，配置保存为 `en-US`；随后正常退出。
