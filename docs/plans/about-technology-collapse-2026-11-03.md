# 关于页技术栈公共展开动画

用户明确要求关于页技术栈使用项目公共展开动画，直接按该方向实施。
问题跟踪：[主仓库 #118](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/118)。

## 修改与范围

- 当前 AboutTab 使用页面专用 technology-expand，基于固定 800px 最大高度，
  与外观页、工具页使用的公共 CollapsiblePanel 不一致。
- 替换为既有 CollapsiblePanel，保留分类默认收起、独立切换、数量及全部技术条目与许可证入口。
  按钮补充 aria-expanded / aria-controls，收起内容沿用公共组件的 inert 限制。
- 公共组件实现及其动效样式保持不变；只移除 animations.css 中已无消费者的关于页专用规则块。
  不调整其他过渡、时长变量或减少动态效果规则，不新增框架或独立动画。

## 验证与交付

按单页局部交互验证。补充技术栈展开/收起和分类独立性回归，运行对应用例及公共折叠组件现有用例；
检查修改文件格式、ESLint、设计规则和含类型检查的构建。
动画文件改动仅删除已确认单页使用的废弃命名规则，其余公共过渡不变，不扩大为无关全量测试。
真实浏览器观察展开/收起的中间高度，确认公共动效速度与减少动态效果、长内容可达、
快速切换、键盘操作、主题和最小/默认/放大窗口。未获远端推送授权，仅交付本地提交。

## 验收结果

- 技术栈回归、关于页卡片标题以及公共面板既有用例共 3 项通过；10 项无关用例未运行。
  首次并行启动测试时系统内存不足，降低堆开销并以单 worker、文件串行重试后通过。
- 修改文件 Prettier、ESLint、设计检查、diff 检查通过，源码已无 technology-expand 调用或规则。
- 构建在限制为 512MB、1024MB 堆时未通过；关闭验收工具、串行分开执行后，
  2GB 堆的 vue-tsc 应用类型检查、tsc Node 配置类型检查、双线程 Vite 生产构建均成功。
  上述步骤与原 pnpm build 检查范围相同，未修改工具配置或跳过类型检查。
- 真实 Edge 浏览器使用实际关于页面：展开记录到 13 个中间高度，收起记录到 8 个中间高度。
  最大分类 28 项完全展开为约 1524px，末项许可证入口可达；收起高度为 0 并恢复 inert。
- 公共倍速 0.5/2 对应展开时长 0.5s/0.125s；禁用动画为 0s，减少动态效果按全局规则近乎立即完成。
  Enter/Space、快速反向切换通过。
- Classic/Folia × 亮暗、背景/70% 透明度/模糊代表设置通过，覆盖 960×600、1200×800、1440×1000，
  展开内容无横向溢出。测试时仅阻断无关的贡献者头像外部请求，不改变技术栈内容。
- 布局、动效采样及截图位于 `output/playwright/about-technology-collapse/`。
  本地提交并同步主仓库前端指针，不推送；#118 保持打开，待远端交付与验收后关闭。
