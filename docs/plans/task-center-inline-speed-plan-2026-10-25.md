日期：2026-10-25。

关联：[任务中心安装进度 #67](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/67) 的后续布局调整。本次是展示位置优化，不另登记缺陷。

## 1. 目标与当前实现

按用户截图，在任务卡名称／阶段右侧、取消等操作按钮左侧的空白区域显示紧凑网速曲线和当前速度。任务阶段、下载进度和速度集中在同一张任务卡中。

调查基线：主仓库 `b4d84d5`，前端 `022e58a`。

- `TaskQueuePanel.vue` 目前在任务列表下面显示独立的 `.tq-live` 实时下载卡，包含任务名、阶段、120px 高曲线、速度、峰值、用时、预计剩余和第二条进度条。
- 每张任务卡已经在进度条下面显示文件数、下载量和一份速度数字，存在信息重复。
- 曲线由 `activeDownload` 选出一个任务，使用一份 `speedSamples`；直接移动现有 SVG 会使多个任务共用同一条曲线，必须同时调整本面板的采样归属。
- 任务卡上部目前为任务信息和操作按钮两列，已有长名称截断、标题提示和键盘展开行为。
- 安装阶段和终态已有权威快照。本次继续读取现有数据，不改后台上报和队列状态模型。

## 2. 已选布局与信息安排

用户已在 A（内嵌小曲线＋速度，替代独立卡）和 B（仅移动速度数字，保留独立卡）中选择 A。

任务卡布局如下，字符示意仅表达区域归属，实际宽度随可用空间变化：

```text
图标  导入实例               紧凑实时网速曲线       79.0 KB/s    取消
      执行中 · 下载加载器安装器
步骤 3 / 8
──────────────────── 当前步骤进度 ───────────────────────── 10%
0 / 1 文件    794 KB / 6.6 MB    已用时 00:08    预计剩余 01:17
```

具体行为：

1. 任务名和阶段留在左侧，曲线与速度在中部至右侧自适应铺开；取消、刷新、移除和查看结果仍是独立操作区域。
2. 小曲线与任务信息两行接近等高，目标约 36—44px。图表使用现有主题色、细线和轻量填充，不增加独立卡片、标题栏或大块背景。
3. 当前速度固定在曲线右侧，数字与绘图区留出空间，使用现有等宽数字样式；已知速度为零时显示 `0 B/s`，尚无有效速度时显示 `—`。
4. 删除下方独立实时下载卡以及它重复的任务名、阶段、文件数和第二条进度条。每项任务仍只有一条当前步骤进度条。
5. 进度条下面继续展示文件数、下载量或实际传输量。用时和预计剩余改为同一统计区中的紧凑文本，不再使用两张数字卡；移除该处重复的速度数字。
6. 峰值与采样窗口说明放入展开详情的简短统计文字，继续复用现有国际化文案，避免把曲线区域塞满标签。
7. 已知可靠字节总量且速度有效时才估算当前下载步骤剩余时间；未知总量保持 `—`，不引入新的整体安装耗时估计。
8. 进入准备／安装处理或任务完成、失败、取消后隐藏当前网速区域，避免显示旧曲线和旧速度。原有阶段说明、错误详情及操作反馈继续由任务状态决定。

## 3. 多任务、采样与资源生命周期

采样只属于任务中心面板，不进入共享 store，也不建立新的下载服务。

- 沿用一个面板级秒级定时器，同时为当前可识别的各个运行中下载任务采样；每个任务独立保存最多 60 个样本。
- 安装任务的采样身份使用稳定任务 ID 和当前安装步骤 ID。切换下载步骤时重置该任务的历史，普通进度更新不清空历史。
- Java、自定义下载和普通 operation 沿用当前已有下载指标的识别范围，不解析文案猜测阶段，不增加后端协议字段。
- 列表插入、排序和删除不能交换曲线；每张卡只能读取自己的采样数组，不再使用选中的全局 `activeDownload`。
- 任务离开可识别下载状态或被移除时释放其采样记录；没有活动下载时停止定时器。
- 面板关闭和组件卸载时停止采样并清理记录；重新打开从当前最新速度开始采样。后台任务和应用级事件订阅继续运行。
- 没有样本时不绘制假波动，一个样本仅反映当前点；零速采样可以画平线，不能沿用旧的非零速度冒充传输。

## 4. 窗口、主题与交互

- 调整 `.tq-task-top` 为任务信息、网速区域和操作区域的自适应布局；使用 `min-width: 0` 和既有间距变量，不通过绝对定位覆盖标题或按钮。
- 最小窗口下优先缩短曲线，长名称仍可截断并通过既有 title 查看完整内容。若长译文和操作按钮使三列无法同时容纳，允许网速区域在同一卡片内换行，仍位于进度条上方。
- 图表区域是任务标题按钮的同级展示区域，不新增嵌套按钮，不抢占取消等操作的点击区域。原有 Enter／Space 展开行为保持可用。
- SVG 只承担视觉曲线，当前速度有独立可读文本；需要补充可访问名称时使用六语言插值，不让每秒采样触发连续播报。
- 覆盖 Classic／Folia、亮／暗、背景、透明度和模糊设置；使用现有主题色和边框规则。
