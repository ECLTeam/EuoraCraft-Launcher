# 实例启动配置恢复入口与局部控件布局

用户要求移除实例设置顶部继承摘要，将恢复按钮放在启动配置标题栏右侧并先确认；
同时修正窗口尺寸乘号对齐、加宽窗口标题输入及启动器行为下拉框。按明确指令直接实施。

问题跟踪：[实例设置恢复入口与控件布局 #116](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/116)。

## 实施

- 复用现有 UiCard 的标题和 actions 插槽承载启动配置，不修改公共组件或引入新包装。
  删除原摘要及废弃样式，保留原表单内容和卡片内间距，标题操作栏仍为紧凑高度。
- 使用已有 ConfirmDialog，沿用自动父弹窗归属、键盘、焦点及加载关闭约束。
  用户确认后才调用已有恢复流程；取消不恢复，执行中防重复，失败后可在确认框重试。
- 目标或弹窗可见性改变时关闭旧确认，恢复结果继续受既有实例目标校验保护。
- 复用按钮文字作为确认标题，新增确认说明同步六语言，移除已无调用的两项摘要文案。
- 窗口尺寸控件居中，乘号使用单行高度；窗口标题和启动器行为使用局部自适应宽度，
  约为内容区六成，上限 600px，不改变其他设置行。

## 验证

按单页局部交互变更验证：更新现有实例设置回归，覆盖确认前不执行、取消、确认成功、
重复确认、失败恢复和目标切换；保留原自动保存/恢复顺序检查。
执行修改文件格式、Vue ESLint、设计检查、六语言键与插值及含类型检查构建。
真实浏览器查看标题操作、确认层级与焦点、乘号对齐、宽控件及主题和窗口适配。
不运行无关全量测试或启动原生启动器。

## 启动前命令框补充调整

用户补充要求扩大“启动前执行命令”输入框。该框缺少相邻命令输入使用的 `argument-input` 类，
空值时随设置行的内容宽度收缩。仅补齐这一局部视觉类，复用相邻命令输入的自适应宽度，
不改变命令值、继承判断、自动保存或执行流程。保留原有两行起始高度与内容增高行为。
使用真实浏览器检查空值、长命令、最小/默认/放大窗口和主题，并执行文件格式与 ESLint 检查；
更新本地构建，不新增镜像实现的测试或运行无关全量用例。

实际验收：Classic/Folia × 亮暗及背景、透明/模糊代表状态通过，覆盖 960×600、1200×800、1440×1000。
最小窗口宽约 412px，其余代表窗口宽 430px，均与相邻包装器命令框同宽；长命令换行增高且无横向溢出。
Prettier、ESLint 和含类型检查的构建通过；仅修改一处视觉类，未重复运行无关功能用例。
浏览器使用预览实例且屏蔽设置写入，不执行命令；截图保留于 `output/playwright/pre-launch-command-width/`。

## 结果

- 实例设置组件定向测试 10 项通过，覆盖取消、确认、重复操作、失败重试、目标切换及原有自动保存。
- 修改文件 Prettier、Vue/测试 ESLint、设计检查、六语言键与插值检查通过；
  `pnpm build`（含类型检查）通过，仅有现有大包体积提醒。
- 使用真实 Edge 浏览器检查实际实例设置页面，预览 API 使用模拟数据，不写入用户实例。
  验证确认前不恢复、Esc 取消及焦点返回、执行中阻止关闭、完成后关闭并禁用恢复按钮。
- 检查 Classic/Folia 与亮暗主题、透明度 70% 和模糊设置，覆盖 960×600、1200×800、1440×1000。
  标题操作栏保持 48px，按钮位于右侧；乘号与输入框中心差为 0px。
  两个加宽控件在最小窗口宽约 412px，默认窗口宽约 472px，未超出设置行。
- 浏览器截图保留于本地 `output/playwright/instance-reset-confirmation/`。
- 本次仅修改单页交互和局部样式，未修改公共组件、后端或持久化契约，因此未运行无关全量测试。
