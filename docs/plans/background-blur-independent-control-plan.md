# 背景模糊独立控制修复实施方案

状态：用户已选择方案 1 并确认实施；已完成修复及验证。

## 需求与验收目标

修复“设置 → 个性化 → 背景模糊”滑杆调整后看不到效果的问题，将背景媒体自身的模糊与额外毛玻璃层分开控制。

- 背景模糊滑杆继续使用 0–20px 范围，调整后立即应用于图片、轮播/随机图片、视频及视频封面。
- 关闭“背景模糊层”后，滑杆仍然有效；关闭状态不能强制清除背景媒体自身的模糊。
- “背景模糊层”开关只控制既有的额外毛玻璃层，不修改滑杆数值和图片/视频的滤镜。
- 额外毛玻璃层使用主题既有的玻璃模糊强度，不再使用背景媒体滑杆的数值。
- 在经典与 Folia 主题、亮色与暗色下均保持上述行为；从 Folia 切回经典后，隐藏的开关状态也不能使滑杆失效。
- 修改后的滑杆值正常保存，重新启动后恢复；原有滑杆值与开关状态继续兼容。

## 当前代码与问题原因

本次按主仓库记录的前端提交 `7b41fe0e0905b520a699b2602bb2f88c8948164c` 排查。

| 位置 | 当前行为 | 问题 |
| --- | --- | --- |
| `frontend/src/views/settings/AppearanceTab.vue` | 滑杆调用 `setBlurAmount` 即时预览，并通过 `patchUiTheme` 防抖保存 `blur_amount`。 | 模糊层开关只在 Folia 主题中显示，滑杆在两种主题下都可操作。 |
| `frontend/src/composables/useTheme.ts` | 将滑杆值写入 `--bg-blur`；将开关状态写入 `data-aurora-blur`，并在本地保存开关状态。 | 两种状态已分别管理，可以沿用，无需新增配置字段。 |
| `frontend/src/styles/app.css` | 图片与视频共用 `.app-background` 的 `filter: blur(var(--bg-blur))`；额外遮罩也使用同一个变量做背景模糊。 | 媒体自身模糊与额外毛玻璃层共用强度，控制含义不清。 |
| `frontend/src/styles/folia.css` | `data-aurora-blur='0'` 时同时清除 `.app-background` 的滤镜和遮罩的背景滤镜；另有 Folia 主内容区的关闭规则。 | 开关覆盖了滑杆的结果，且背景关闭规则并未限定主题，因此经典主题也受已保存的关闭状态影响。 |

这是源码中能够确认的控制冲突；实施时仍需在真实渲染环境验证用户报告的表现及修复效果。

## 已选择方案与取舍

采用方案 1：分开控制背景媒体模糊和额外毛玻璃层。

方案 2 是保留总开关联动、关闭后禁用滑杆并显示提示，用户未选择。

分开控制后，关闭额外毛玻璃层并不等于背景完全清晰；若需要清晰背景，应同时将滑杆设为 0。开启额外毛玻璃层时，其主题玻璃效果仍可能让画面显得更模糊，因此文案和验收必须明确两种效果的区别。

## 具体改动范围

### 1. 调整媒体与遮罩样式

- 在 `app.css` 中保留 `.app-background` 使用 `--bg-blur` 的媒体滤镜，图片与视频沿用同一规则。
- 将 `.app-background-overlay` 的额外背景模糊接到主题既有的玻璃滤镜变量 `--glass-backdrop`；同时保留标准与 WebKit 属性。
- WebKit 声明放在标准声明之前，避免构建优化仅保留前缀版本；相同调整限定于本次涉及的遮罩与 Folia 主内容区规则。
- 经典主题沿用其既有玻璃变量默认行为；Folia 沿用其既有玻璃强度，不引入新的强度设置。
- 在 `folia.css` 中移除关闭开关时针对 `.app-background` 的滤镜清除规则，仅关闭 `.app-background-overlay` 的背景滤镜。
- 保留开关对 Folia `.main-content` 额外背景模糊的既有控制，不扩展为所有卡片、侧边栏和控件的全局玻璃开关。
- 保留遮罩色调、背景亮度、背景缩放、层级和媒体播放逻辑。

### 2. 调整设置文案

- 更新六种已有语言的“背景模糊层”说明，表达为额外毛玻璃效果，并说明关闭不会影响背景媒体自身模糊。
- 更新“背景模糊”说明，覆盖图片与视频，说明独立于毛玻璃层开关。
- 若需消除歧义，可将开关显示名称改为“额外毛玻璃层”，沿用现有翻译键。
- 保留设置布局及开关在 Folia 中的现有显示范围。

### 3. 配置兼容

- 沿用 `ui.theme.blur_amount` 和现有本地模糊层开关存储键，不改写用户已保存的数值和开关状态。
- 不新增后端配置，不迁移历史 `ui.background.blur`，不调整后端默认值。
- 实施时验证当前滑杆保存与恢复链路；若发现独立的保存故障，先说明影响和新增改动范围，再按项目规范处理。

### 4. 回归测试

- 在既有 `useTheme.test.ts` 中补充两种状态互不覆盖的行为测试：先关闭模糊层，再将滑杆改为非零；切换主题后仍保留数值与对应变量。
- 通过浏览器实际加载修改后的样式，断言关闭开关时媒体的计算滤镜仍为目标模糊值、额外遮罩的背景滤镜为 `none`。该用例必须在修复前失败、修复后通过，避免仅测试状态而漏掉本次 CSS 覆盖问题。
- 覆盖图片与视频使用相同媒体滤镜，以及开关开/关、滑杆为 0/非零、经典/Folia、亮色/暗色组合。
- 核验重启后滑杆值和开关状态恢复；使用独立测试数据目录，不覆盖日常启动器设置。
