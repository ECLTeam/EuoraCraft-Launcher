# 插件设置按钮及卡片头部紧凑化

用户要求插件列表头部设置按钮改为圆形，并统一实例设置与 Java 管理卡片标题行高度。
用户已确认实例设置指实例详情里的“设置”页，按明确指令直接实施。
关联 [#115](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/115)。

## 现状与实施

- 插件设置入口沿用 Naive UI `NButton`，增加现有 `circle` 属性；保留提示、可访问名称与点击行为。
  工具栏使用最小间距，使 Folia 分段控件不会把头部从 48px 撑到 50px。
- 实例设置内部的分区标题本身约 48px，顶部摘要因为两行文字加 12px 上下内边距达到约 66px。
  保留两行信息，将上下内边距改为现有最小间距，文字行高调整为 1.3，沿用最小 48px。
- Java 标签组本身 38px，加上下内边距达到 61px。标签组收为 32px，内部按钮为 28px，
  工具栏使用现有小间距及最小 48px；操作按钮仍为 32px。
- 三处均为局部调整，不修改公共卡片、按钮实现或全局主题；长译文及窄容器必要时换行，避免固定高度裁切。
- 相比重写公共头部组件，本次沿用各页面已有所有者，避免影响无关页面。

## 验证

定向检查修改文件格式、Vue ESLint、设计规则与含类型检查构建；只运行插件页现有入口用例。
在真实浏览器对比调整前后高度，查看 Classic/Folia 亮暗、最小/默认/放大窗口及德语代表状态，
检查圆形按钮点击、悬停和焦点，Java 两个页签与实例摘要的长名称。
纯视觉改动不新增机械测试，不运行全量测试或启动原生启动器。

## 结果

- 插件设置按钮为 32×32px 圆形，提示和可访问名称保留，键盘 Enter 可打开设置弹窗。
- 实例设置顶部摘要由约 66px 收为 48px，Java 管理栏由 61px 收为 48px；
  插件栏在 Classic/Folia 下均为 48px，正常单行布局对齐。
- 真实 Edge 浏览器覆盖三个区域的 Classic/Folia 亮暗及 960×600、1200×800、1440×1000，
  未发现水平溢出。德语最小窗口中，实例摘要仍为 48px；Java 操作较长时自动换为两行，
  保留所有操作。查看 Java 已安装/下载页签的空数据或读取失败状态，不代表实际 Java 下载验收。
- 修改文件格式、Vue ESLint、设计检查、`git diff --check` 通过；插件页现有定向用例通过。
  含类型检查构建通过，最后的纯 CSS 间距调整后重新生成前端产物。
  构建保留已有大分块提示，没有运行无关全量测试或启动原生启动器。
- 记录与截图位于 `output/playwright/compact-card-headers/`，包含三处最终预览。
