# Java 下载全屏入口与列表调整方案

状态：待用户确认，尚未修改产品代码。

关联建议：[主仓库 #117](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/117)。

## 需求与现状

用户希望下载使用全屏弹窗，Java 管理列表与项目其他列表一致，并移除列表中的下载进度。
本方案将截图中的列表理解为已安装 Java 列表，将“下载弹窗”理解为点击 Java 下载入口后显示的目录。

- `JavaTab.vue` 在一张撑满内容区的 UiCard 内挂载 `JavaManagerPanel.vue`。
- 面板目前通过“已安装 / 下载”切换同一块内容；下载并非独立弹窗。
- `JavaManagerModal.vue` 已为实例及全局 Java 选择器提供统一全屏管理入口，需保留其选择语义。
- `JavaManagerPanel.vue` 底部另有 `java-operation-row`，重复呈现进度、消息、刷新和取消。
- 应用运行时已把 Java 安装、移除和清理任务接入 applicationOperationStore 和统一任务中心。
  任务中心已使用 FullscreenModal；此次调整不修改任务中心的进度展示。

## 可选方案

| 方案 | 行为与取舍 |
| --- | --- |
| A：下载独立全屏（推荐） | 设置页保留已安装列表；“下载 Java”按钮打开全屏目录。界面职责清楚，保留当前管理入口。 |
| B：整个 Java 管理移入全屏 | 设置页只留入口，已安装和下载都在全屏管理内。空间更大，但增加查看已安装 Java 的操作步骤。 |

以下为 A 的可执行方案。用户选择 B 时先修订文档。

## 目标界面

1. 设置页卡片头部显示 Java 管理标题；下载改为操作按钮，与重新扫描、检查更新、添加现有 Java 同处标题操作区。
2. 搜索下方采用插件列表已有的紧凑分隔行、悬停、边距和信息层级。
   左侧无外框图标与运行时名称/供应商、JRE/JDK；其后对齐完整版本和架构/来源信息、状态与最右侧操作。
   保留“设为全局 Java”或选择场景的“使用”主要按钮，路径和更多入口保留完整说明及可访问名称。
   正常状态不额外堆叠标签，无效、禁用、使用中或有引用时保留实际状态信息和操作限制。
3. “下载 Java”打开项目现有 FullscreenModal，标题为 Java 下载。
   内容为一张自适应卡片：顶部版本、JRE/JDK 和刷新筛选，下面显示来源及下载包列表。
   下载包也使用相同的紧凑行排版，右侧保留下载并安装操作。
4. 删除管理面板里的整块重复任务进度区域，包括其中的进度条、百分比和任务操作。
   安装提交后仍给出已有任务提交反馈，进度、取消和查询失败恢复统一在任务中心处理。
   关闭全屏目录不停止下载和安装。

## 修改点与步骤

1. 调整 `JavaManagerPanel.vue` 和 `JavaManagerPanel.css` 的工具栏、搜索及已安装行布局。
   删除仅服务重复进度区的 computed、组件导入和 CSS，保留清理警告及重试入口。
2. 将下载目录及筛选搬入 Java 业务下的下载全屏组件；直接复用现有 FullscreenModal、UiCard 和目录 API。
   不修改公共弹窗实现，不新增通用 UI 包装或另一份 Java 清单状态。
3. 安装继续先生成计划、显示既有确认内容，再提交现有 API。下载确认必须属于当前下载全屏层。
   原已安装列表中的更新、删除确认保留各自流程；不更改确认文案表达的下载大小、位置和空间信息。
4. 调整 Java 选择器全屏入口的下载打开行为，保留 requiredMajor、scopeKey、实例目标和选择返回。
   筛选变化、关闭、实例切换后，旧目录或安装计划响应不得重新打开弹窗或覆盖新选择。
5. 保留应用级任务跟踪及 Java 清单刷新链路；确认移除重复进度后，后台成功结果仍更新已安装列表。
   不改变后端、IPC、持久化、安装安全校验或公共任务 store。
6. 新增或修改的标题、按钮及可访问文案同步六语言；长名称可查看完整内容。

## 验收与交付

按局部前端交互变更做定向验证，不运行无关全量测试。

- 更新 JavaManagerPanel、JavaTab 及受影响 Java 选择器测试：下载打开独立全屏而非替换管理卡片；
  取消不安装、确认只提交一次、失败可重试、旧筛选/实例响应失效；管理列表不再渲染任务进度。
- 选择统一任务中心已有的 Java 任务用例，验证移除局部展示后仍可跟踪、取消和恢复查询；
  未改动公共任务实现时不扩大到无关全量任务测试。
- 改动文件 Prettier、ESLint、设计检查、类型检查、六语言键/插值检查及前端构建。

  确认 Esc 层级、焦点恢复、关闭后任务继续及成功后清单刷新。
- 检查 Classic/Folia、亮暗、背景与透明/模糊代表状态，视口覆盖 960×600、默认和放大尺寸。

- 通过后分别提交前端及主仓库指针到本地 main，不推送；#117 保持打开，远端交付并验收后关闭。
