## 2. 当前情况与设计依据

调查基线：主仓库 `429816b`，前端 `d69a884`。实施前重新核对实际工作区。

- `Plugins.vue` 根据 `plugin.error` 渲染独立 `.plugin-error` 文本；同一行已经有运行状态标签。错误翻译及未知错误回退由现有 `pluginError()` 处理。
- 设置左侧按钮使用两行网格，名称及技术标识都在选中时使用强调色；右侧使用 16px 标题和独立的标识/版本行，再叠加卡片及标题内边距。
- 现有侧栏 `SectionLayout.css` 的菜单项高度为 36px；左侧分区标题为 44px。现有 `SettingSection.vue` 的标题使用 13px 字体及紧凑上下边距。
- 本轮复用既有 Naive UI 提示组件、主题表面和菜单视觉值，不修改公共卡片、主题变量或路由布局来迁就此页面。

## 3. 插件列表状态提示

1. 删除名称下方的错误文本节点和专属 `.plugin-error` 样式；列表保留图标、名称、简介、版本、状态和既有操作。
2. 有 `plugin.error` 时，在主状态标签上提供按需提示，沿用 `pluginError()` 的翻译与既有错误回退，不改变错误数据或错误判定。
3. 使用已有提示组件定位浮层，避免被列表滚动容器裁切；不新增页面常驻错误区或额外错误按钮。
4. 提示支持鼠标悬停及键盘焦点，焦点具有主题规定的可见轮廓；Esc 可收起，移开或离开焦点后释放提示状态。鼠标离开时，仍持有键盘焦点的提示不得被误关。
5. 将提示与状态标签建立可访问描述关系。正常插件不增加无意义的提示或额外键盘停靠点；状态文字与状态颜色继续沿用现有规则。
6. 保留日志、启用失败反馈和授权判断，不将移除列表红字等同于忽略插件错误，也不新增自动启用、重试或授权行为。

仅在页面内维护必要的悬停/焦点状态，实际显示值由这些状态派生；不新增全局 store、定时轮询或通用提示框架。复用现有六语言错误键；若确需新增用户文案，同步六语言及插值。

## 4. 设置界面的紧凑布局

### 4.1 左侧插件列表

- 保留搜索框、现有稳定安装身份、选择逻辑及列表滚动边界。
- 每项只显示插件名称；名称缺失时继续用插件标识兜底。技术标识从常驻第二行移到完整信息提示中，不删除业务字段。
- 沿用现有列表按钮和选中机制，将行高、字重及留白对齐现有约 36px 的菜单项；不再把每个条目显示成双行粗体块。
- 长名称可省略但可查看完整名称及标识，鼠标和键盘都可选中，当前选中项保留清楚的主题色背景与焦点。

### 4.2 右侧卡片标题

- 标题按“插件名称 + 版本”同一行排列，名称字号及字重对齐普通设置分组标题；删除单独的标识/版本副标题行。
- “打开插件目录”继续使用现有小尺寸按钮并靠右，仅对现有支持的目录安装显示，保留原事件。
- 将标题区和正文内边距分开管理，分隔线及留白对齐现有卡片边界。默认字号下标题区以约 44–48px 为验收基准，不使用固定高度裁切字体或控件。
- 长插件名优先省略并提供完整信息提示；版本、目录按钮保持可达，不因名称较长把标题推回两行。
- 正文继续撑满剩余区域并按现有方式滚动。空设置提示、加载、失败、保存反馈及控件排布保持原行为。

保留 `.ecl-surface` 的公共圆角、边框、透明度和模糊；不重新定义外观变量，也不修改公共 `SectionLayout` 的路由选择接口。

## 6. 定向测试与验收

本轮是两个已确认直接相关界面中的局部交互与样式调整，不改变公共组件、共享业务状态、IPC、持久化、插件执行或授权规则。按主仓库规范 6.1 的前端局部交互类别执行定向验证，不运行全量 Vitest、全量 pytest 或无关后端测试。

在 `frontend` 执行变更文件的 Prettier、ESLint，执行 `pnpm check:design`、`pnpm typecheck`，以及：

```text
pnpm exec vitest run src/views/Plugins.test.ts src/features/plugins/components/PluginSettingsModal.test.ts
```

通过后执行 `pnpm build`，使用生产前端实际启动启动器。新增或调整的原生验收 Python 脚本单独做 Ruff 和格式检查。

必测行为：待审阅、运行失败、未知错误及正常状态均不显示名称下方错误行；有错误时悬停/聚焦能读取原因，离开及 Esc 收起，长提示不被裁切。设置列表能搜索、切换和定位当前插件，标识仍可查询；右侧名称和版本保持完整可访问，目录操作及保存去重、保存失败、旧响应隔离、关闭约束和焦点恢复保持原有结果。

真实布局覆盖 Classic/Folia × 亮暗、960×600、默认和放大窗口，以及六语言长名称/译文、相关图片背景、透明度和模糊状态。检查左侧单行密度、右侧标题高度、正文可用空间、滚动末项及键盘焦点，人工查看代表截图；不能仅靠 jsdom 断言几何尺寸。
