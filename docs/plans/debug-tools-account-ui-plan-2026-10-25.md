## 3. 具体设计

### 3.1 显示偏好与恢复入口

在 `UiConfig` 增加可选的 `debugTools` 对象：

```ts
debugTools?: {
  visible?: boolean
  minimizedShape?: 'rectangle' | 'circle'
}
```

- 未设置时按首次使用默认值处理：`visible = true`、`minimizedShape = 'rectangle'`。这两个字段是新偏好，不引入历史字段别名、双格式读写或迁移。
- 在 `settingsSnapshot.ts` 同步增加布尔与枚举运行时校验。明确非法类型或形态时报配置校验错误，不以任意字符串绕过校验。
- `settingsStore.ui` 是偏好的唯一维护者。通过现有串行 UI 更新流程合并 `debugTools`，保留同分区其他设置；不另存 localStorage，也不把相同偏好复制到窗口 store。
- 将用户的“关闭工具”与工具因调试模式关闭、协议未接受等原因暂不可用区分。只有用户主动关闭才保存 `visible = false`；关闭调试模式不覆盖用户偏好。
- 显示偏好加载完成后再决定自动激活。关闭后切页、普通弹窗开关、全屏管理页切换和重启均不能重新显示；重新开启调试模式也尊重已保存偏好。
- 设置中保留“打开调试工具”，增加“显示悬浮入口”和“收起形态”。打开操作先成功保存显示偏好，再展开工具；关闭操作成功保存后隐藏。保存期间阻止重复提交，失败时保留当前状态并显示错误，允许重试。
- 偏好只保存显示与形态。展开面板的内容、坐标和大小沿用现有运行时管理，不扩大为窗口布局持久化。

### 3.2 圆形与矩形交互

- 矩形维持现有标题、图标及还原布局，增加关闭按钮；展开面板也增加关闭按钮。
- 圆形使用 44×44 的单图标按钮，点击或 Enter/Space 展开，拖动只移动。通过小幅移动阈值区分点击与拖动，拖动结束不能误展开。
- 圆形保持单图标外观，展开后可关闭；也可随时在设置中关闭。标题以 tooltip 和可访问名称提供。
- 坐标约束按当前形态实际宽高计算，移除矩形宽度对圆形拖动边界的影响。切换形态、容器缩放和窗口尺寸变化时重新约束，入口不能落在可视范围之外。
- 沿用页面和全屏弹窗的宿主、普通弹窗阻挡、焦点恢复与手势清理。关闭或形态变化时终止活动手势，释放指针捕获与事件监听。
- 浮窗继续叠加在内容区，不增设占位、不减少页面可用高度；样式沿用主题变量。

### 3.3 离线账户表单

表单顺序为：用户名、UUID、默认皮肤、添加按钮。

- 删除高级选项按钮、折叠状态、过渡和专属样式；直接显示带可访问标签的 UUID 输入框。
- 自动模式下，将后端派生的 UUID 作为输入框实际可见值展示；不只使用容易被忽略的 placeholder。简短说明“自动生成，可修改；清空后恢复自动生成”。
- 通过明确的输入值绑定区分“框内显示的自动值”和“用户手动值”。继续让 `newOfflineUuid` 仅代表手动覆盖，避免仅预览后就把自动值当成自定义 UUID 提交。
- 用户修改 UUID 后进入手动覆盖；修改用户名不能覆盖手动值。清空 UUID 后恢复自动预览；清空用户名时清除自动预览。
- 用户名变化时立即使旧预览和旧请求失效，待最新防抖请求返回后更新；表单重置后旧响应不能回填。预览失败时框内不保留旧值，仍允许后端在提交时按用户名派生。
- 沿用已有 32 位与带连字符 UUID 格式校验；非法值显示就地错误并禁止添加。自动模式提交时仍不传自定义 UUID。
- 默认皮肤列表、加载、清空及添加执行锁沿用现有行为，不扩展为皮肤功能重做。

### 3.4 图标与确认弹窗

- 离线账户使用 Tabler `user-circle`，Authlib 外置登录使用 `server`。图标统一 18px、相同容器与基线，使用主题文字色；插件登录保留 `puzzle`，并纳入对齐验收。
- 在 `iconify.ts` 和离线 `tabler-subset.ts` 中同步维护所需图标。优先使用已包含的图标，新增项从当前依赖的官方 Tabler 图标数据提取，不引入新依赖或在线图标请求。
- 在公共 `ConfirmDialog.vue` 中向 `Modal` 显式传递图标：危险确认使用现有 `warning`，普通确认使用现有 `help`。删除账户自然继承此行为，其他使用同一公共危险确认的入口也同步呈现警告图标。
- 不改变确认、取消、执行中禁止关闭及删除失败后可重试的行为；通过公共组件回归覆盖直接消费方。
- 将总标题及相关入口文案同步至现有六种语言；只清理已无消费者的高级选项和独立预览文案，保留真正用于组件调试的分区文案。
