# 插件行操作改为纯图标

用户要求每个插件最右侧的文字及图标操作统一为纯图标，关联
[#112](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/112)。按明确指令直接实施。

## 实施

- 复用 `UiIcon`：权限用盾牌，面板用网格，设置用齿轮，启用/禁用用播放/停止，重载用刷新，卸载用垃圾桶。
- 每个按钮复用已有六语言文案设置 `title` 和 `aria-label`，保留键盘、禁用、加载及卸载确认。
- 按钮统一 28px 方形、16px 图形；操作区单行排列并显式右对齐，列宽由 210px 收为 184px，表头同步。
- 按用户追加要求，状态列由 96px 收为 80px，状态及版本随之右移；图标组贴齐右侧内边距。
- 相比把操作收入“更多”菜单，直接图标保留每个现有操作的一次点击入口，符合本次要求。
- 更新原有权限入口回归，通过可访问名称定位按钮；定向检查纯图标及名称覆盖。

## 验证

属于单页局部视觉模板变更，检查修改文件的格式、ESLint、设计规则，运行相关入口回归，
执行含类型检查的构建。真实浏览器查看主题与窗口、正常/禁用/重载状态、悬停提示和键盘入口。
不运行全量测试或启动原生启动器。

## 结果

- 修改文件格式、ESLint、设计规则和 `git diff --check` 通过；含类型检查的构建通过。
  构建仍有既有的大分块提示。
- 插件页面及权限入口定向用例通过；不运行无关全量测试。
- 真实 Edge 浏览器查看 Classic/Folia 亮暗及 960×600、1200×800、1440×1000 三种窗口。
  六个操作均为 28px 纯图标，名称与悬停提示一致；操作组最右按钮与行右侧内边距精确对齐，
  没有水平溢出。版本及状态列均较初始布局右移。
- 通过真实按钮检查启用/禁用往返、重载、设置和卸载确认；键盘 Enter 可以打开权限确认。
  授权弹窗数据使用与既有浏览器验收相同方式的测试域响应，不保存实际授权。
  查看加载指示、待重启禁用状态与德语名称；原有设置列表图标仍正常显示。
- 浏览器记录和截图位于 `output/playwright/plugin-action-icons/`，最终截图为 `actions-final.png`。
- 本地提交并集成 main，未推送；#112 保持打开，远端集成与验收后再关闭。
