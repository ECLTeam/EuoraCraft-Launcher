# 插件设置切换过渡

用户指出插件设置全屏弹窗缺少切换动画，按该明确改进要求直接实施。
关联 [#113](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/113)。

## 实施

- 右侧设置内容使用与设置页、实例详情一致的 `page` 与 `out-in`，以选中插件的稳定身份为 key，卡片表面保持固定；
  左侧列表保持固定，选中项的背景与文字颜色使用现有快时长和缓动。
- 离场内容标记 `inert` 和 `aria-hidden`，避免旧表单在离场期间继续操作。
- 继续使用当前请求范围保护；加载、失败、空状态和成功内容均随内容容器过渡，
  不因同一插件保存或重新读取而重播切换动画。
- 复用已有的透明度与轻微位移过渡，避免扩大到公共动效系统。
- 现有公共动画已处理系统减少动态效果，本次不添加时长常量或修改全局动效。

## 验证

仅修改插件设置业务组件，执行定向格式、ESLint、设计检查、现有设置用例及含类型检查构建。
真实浏览器查看普通切换、快速连续切换、加载中切换、离场不可交互、主题及减少动态效果。
不运行无关全量测试或启动原生启动器。

## 结果

- 修改组件的格式、ESLint、设计检查与 `git diff --check` 通过；现有设置组件定向用例通过。
- 含类型检查的 `pnpm build` 通过，保留已有大分块提示。不运行无关全量测试。
- 初轮真实 Edge 浏览器覆盖 Classic/Folia 亮暗及 960×600、1200×800、1440×1000 三种窗口。
  普通切换复用统一页面过渡：150ms 离场、250ms 入场，卡片表面保持可见；动画结束后没有布局溢出或残留 inert。
- 连续切换及人为延迟读取后，最后选择的插件与字段仍一致；离场内容不可交互。
  系统减少动态效果下，计算过渡时长降为 `0.00001s`，切换后正常恢复交互。
- 查看动画中间状态和稳定状态；原始记录及截图位于
  `output/playwright/plugin-settings-transition/`，使用实际 showcase 页面和测试读取延迟。
- 仅进行浏览器验收，无原生能力改动，不启动启动器。完成本地 main 提交及指针集成，
  未推送；#113 保持打开，远端集成与验收后再关闭。

## 统一动效复核

用户指出切换效果未与同类界面对齐。复核确认通用 `fade` 虽然使用统一时长变量，
但与 `Settings.vue`、`InstanceDetailModal.vue` 的 `page` 效果不同；现已直接接入同名过渡，
不复制 CSS 或另设时长。追加验证全局动画速度及关闭动画、减少动态效果的实际表现。

复核后的定向格式、ESLint、设置组件用例、类型检查及构建通过。真实浏览器验证
0.5×、1×、2× 全局速度下的离场时长分别为 0.3s、0.15s、0.075s，均包含透明度与位移；
关闭动画及系统减少动态效果时，切换正常完成。记录位于
`output/playwright/plugin-settings-unified-motion/result.json`。本次只调整业务组件引用的
过渡名称，未修改公共动效或全局设置，因此不扩大为全量测试。
