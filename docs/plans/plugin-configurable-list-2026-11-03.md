# 插件设置列表只展示有配置项的插件

用户要求没有注册配置项的插件不出现在设置弹窗列表中，按明确指令实施。
外部插件管理列表继续展示全部插件。
关联 [#114](https://github.com/ECLTeam/EuoraCraft-Launcher/issues/114)。

## 调查与选择

当前列表只排除系统插件。`PluginInfo.settings` 只在运行时填充，不能据此过滤禁用插件；
既有 `getSettings` 可读取匹配当前内容的已发布定义，不运行插件。
因此在设置弹窗打开时并行读取非系统插件的配置定义，只展示非空 schema。
不改后端或 IPC 契约，不为发现配置启动插件。

## 实施

- 弹窗内部保存按安装身份、内容、运行状态及重载版本绑定的读取结果；过期响应不得加入列表。
- 当前插件没有配置项时选择首个有配置项的插件；移除或变为空配置后也更新选择。
- 保留已经发布配置的禁用插件，复用读取结果展示表单，避免选中后再次读取同一份配置。
- 读取期间显示加载，全部为空显示六语言空状态；读取失败提供重试，不当作没有配置。
- 更新设置事件刷新配置目录，保持现有保存、请求范围保护及统一过渡。
- 目录响应不得回退已经确认的配置版本，也不能在保存过程中重新加载当前表单。

## 验证

单页局部交互变更：新增过滤、默认选择、禁用插件、空列表及失败重试的必要回归，
运行设置组件及页面的定向用例，检查格式、ESLint、六语言文案、类型及构建。
真实浏览器查看有/无配置混合、空列表、搜索与切换。无需无关全量测试或原生启动器。

## 结果

- 过滤空配置、默认选择有配置的禁用插件、读取失败三项回归在修改前失败，修改后通过。
  设置组件及页面采用定向验证，保留已有保存、筛选、迟到响应回归，并验证目录读取不覆盖保存。
- 修改文件格式、ESLint、设计规则及 `git diff --check` 通过；含类型检查构建通过，
  仅保留已有大分块提示。不修改后端、IPC 或公共 store，不运行无关全量测试。
- 复用已有 `plugins.noSettings` 和错误/重试文案，六语言均已有对应翻译，没有新增翻译键。
- 真实 Edge 浏览器使用实际 showcase 页面和合成配置响应，查看有配置/无配置混合、
  已禁用但有配置、搜索无匹配、全部为空、读取失败及重试；外部管理列表仍保留全部插件。
  Classic/Folia 亮暗与三种窗口下的列表布局正常，无水平溢出。
- 浏览器记录与截图位于 `output/playwright/plugin-configurable-list/`。
