# 账户定位栏默认颜色预览实施方案

状态：2026-10-13 按用户最终范围完成实现与必要的定向验证。仅在账户详情显示颜色，已删除颜色来源说明句；未运行全量测试。

## 目标与选定范围

在启动器账户详情区展示所查看账户的 Minecraft Java 定位栏默认颜色，让用户直接看到自己的标记颜色。

用户最初选择方案 A，后续明确收窄为：仅在账户详情展示色块、色值和复制按钮，去除颜色来源与覆盖说明。使用已保存的账户 UUID 在前端本地计算。

此前比较过的其他方案：B 在预览基础上加入定位栏模拟和 `/waypoint` 命令生成，交互和版本适配范围更大；C 增加外部网站入口，实现更轻但查看时依赖网络和外部页面。第一版采用 A。

## 调研与影响分析

- `frontend/src/components/game/GameAccountCard.vue` 为首页账户卡片；按最新要求保持现有展示。
- `frontend/src/views/Game.vue` 已有账户详情窗口及 UUID 信息行，可加入颜色值和复制操作，不需要新增弹窗。
- `frontend/src/types/accounts.ts` 的 `MinecraftAccount.uuid` 为可选字段；Microsoft、离线、Authlib 和插件账户共用此模型。
- `ECL/services/account/accounts.py` 添加离线账户时已生成或校验自定义 UUID，并将其保存在账户信息中；游戏启动使用账户凭据 UUID。展示使用现有 UUID，不根据账户昵称重新生成或查询。
- `accountStore.ts` 已响应账户切换和快照变更。颜色作为 UUID 的计算结果，可随数据同步更新，不引入额外缓存或异步请求。
- 预计难度较低至中等：主要工作为算法准确性、详情复制反馈和国际化。生产改动仅涉及前端，后端协议及账户持久化格式无需扩展。

## 展示与交互

### 账户详情

- 新增“定位栏默认颜色”信息项，展示色块、六位大写 HEX 和复制按钮。
- 复制内容固定为 `#RRGGBB`。成功后使用既有轻量提示；复制失败提示用户，并保留可选择的色值文本供手动复制。
- UUID 缺失或格式无效时显示“暂无可用 UUID”，不展示色块或复制按钮。
- 用户要求删除颜色来源说明句，界面仅保留颜色信息和操作。

## 算法与数据边界

1. 接受去除首尾空白后的标准 `8-4-4-4-12` UUID，或不带连字符的 32 位十六进制 UUID；大小写等价。其他输入返回不可计算结果。
2. 按 Java `UUID.hashCode()` 折叠 128 位 UUID，读取低 24 位颜色。
3. 按客户端默认颜色处理设置 HSV 亮度，保留色相和饱和度；实现时核验官方客户端的实际转换与 Java 单精度舍入，不能用 RGB 直接乘 0.9 或直接输出原始哈希色替代。
4. 输出明确类型的只读颜色结果（HEX 与 RGB），无效 UUID 返回 `null`；组件不直接处理哈希细节。
5. 全零 UUID 和灰色哈希均按有效输入处理。颜色可能重复，不将其用作账户标识。
6. 使用已存储 UUID，包括自定义离线 UUID；不推测服务器最终使用的 UUID，不修改账户数据或游戏内颜色。
7. LocatorBar 网站作为需求与算法调研参考，独立实现本地计算；不嵌入第三方页面、脚本或资源，不复制其网站实现代码。
