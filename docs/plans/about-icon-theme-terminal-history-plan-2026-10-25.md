## 1. 现状与原因

调查基线：主仓库 `f6a94655e1ba5297bbc810c7a5250a4e970a4c64`，前端 `f3114cd175494ea33c48f7644658911b3b4e5898`。两个原工作区均在本地 `main`；主仓库原有无关的 ADR-051 删除须保留。

- 关于页已为六张卡片补齐 UiIcon，但本页 `.card-title` 使用 `var(--text-primary)`，图标随之继承正文色。公共 Card 的 `.header-content .icon` 使用 `var(--primary)`，因此呈现不同。
- 实例终端的历史和输出由应用级 `useProcessInstances.ts` 集中维护，页面只是消费者。每个会话最多保留 300 行，自动回收保留约 20 个停止会话并保护当前选中项，目前没有手动移除能力。
- 后端 `ProcessService` 在游戏结束或子进程退出时已经清理对应登记及输出缓冲。当前保留的已退出记录属于前端应用会话，无需新增后端删除命令。
- 现有 `onLog` 会为未知进程建立临时会话。只删除列表项会被迟到日志重新创建；只删输出也无法完成用户要求的记录移除。
- `refresh()` 已用快照修订号拒绝旧响应，移除行为也需要推进这一修订号，避免移除前发起的查询覆盖新状态。

## 2. 已选择方案与范围

用户已在 A（单条移除并一键清除）和 B（仅单条移除）中选择 A。

1. 关于页六个卡片标题图标统一使用主题色，标题文字保持正文色。
2. 实例终端的已退出会话提供单条“移除记录”。
3. 列表操作区提供“清除已退出记录”，一次清除全部已确认停止的会话。
4. 清除对应会话的内存输出和停止排序信息，更新选中项，并阻止迟到日志恢复已移除记录。
5. 运行中及尚待快照确认的会话不允许移除，批量操作也跳过这些项。
6. 仅整理本次应用会话的终端历史，不停止进程，不删除实例、存档或磁盘日志；不新增持久化、后端 IPC、历史兼容入口或通用框架。

## 3. 关于页样式

## 4. 终端状态与事件处理

在现有 `useProcessInstances.ts` 控制器新增单条移除和批量清除公开方法，页面不直接操作其数组或输出对象。

### 4.1 移除条件及状态提交

- 以当前权威会话的 `state === 'stopped'` 判断可移除；不存在、运行中或 `unknown` 时不改变状态。
- 单条移除同步更新 `sessions`、`outputByProcessId`、停止排序和移除标记，再推进快照修订号，使移除前的异步刷新结果失效。
- 移除未选中项时保持当前选择；移除选中项时优先选择剩余运行会话，其次选择相邻保留会话；没有会话则清空选择并显示现有空态。
- 批量清除先取得本次确认停止的 ID 集合，再统一提交删除；保留运行中和未知会话。再次执行没有可清除项时无副作用。
- 继续使用现有自动数量回收，不为手动操作保留多份独立历史列表。

### 4.2 迟到日志和查询

- 在应用级控制器内维护本次应用会话已手动移除的进程 ID，日志事件不得为这些 ID 重建历史；已移除会话的停止快照也不得恢复条目。
- 标记与控制器共享生命周期，切换页面不释放，应用级最终释放时统一清理；不写入配置或长期存储。
- 后端确认为正在运行的进程仍应展示，不能因历史移除标记隐藏真实运行状态；新启动一般使用新的进程 ID。
- 移除/清除推进现有快照修订号，沿用 `generation` 和请求修订机制，避免新增一套订阅或轮询。

## 5. 终端界面与交互

- 修改 `ProcessInstanceView.vue`，在每个已停止会话旁提供独立的移除图标按钮，包含名称插值的可访问标签和悬停提示。
- 当前列表行是原生 button。增加操作时将选择按钮和移除按钮放在同行容器中，禁止在 button 内嵌 button；点击移除不会触发会话选择。
- 在左侧列表顶部增加紧凑操作区，放置“清除已退出记录”；没有已停止记录时禁用。列表项作为主要滚动区，操作区固定可达。
- 支持鼠标和键盘；移除焦点所在行后将焦点移到保留会话或空态容器，不遗留在被删除节点。
- 不增加删除文件性质的二次确认弹窗；按钮文案明确移除的是终端记录。
- 复用既有主题变量、按钮图标和局部样式，保持列表宽度及输出区域适配；长名称可查看完整文本。
- 所有新增按钮、提示及可访问文案同步六语言。

## 7. 验证目标及本轮执行限制

回归用例维护目标：

- 六个标题保留图标及文字，图标使用主题变量。
- 单条移除同时清理记录、输出和停止排序，不移除运行中或未知会话。
- 批量清除保留运行会话，重复执行安全，选中项变化和最终空态正确。
- 移除前的查询响应、停止快照及迟到日志不能恢复已移除历史，真实运行会话仍可显示。
- 点击移除不触发选择、不调用进程停止接口，纯图标按钮有可访问名称；列表不嵌套交互控件。
- 删除后焦点可达，长名称、列表末项、操作区和终端输出布局不互相挤占。

正常情况下应执行前端定向检查、相关组件/composable 测试，以及默认、960×600、放大窗口的 Classic/Folia、亮暗和主题色真实验收。用户明确要求不再测试，因此本轮全部跳过，不将代码阅读或格式写入描述为测试通过。
