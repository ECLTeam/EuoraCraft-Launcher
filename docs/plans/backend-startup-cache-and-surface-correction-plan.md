# 启动预热职责与卡片视觉修正方案

状态：用户已选择 A；按用户后续要求恢复原卡片透明度，保留后端职责与按需查询修复。

## 已确认的现状

- `frontend/src/App.vue` 在运行时就绪、协议通过后延迟 500ms 调用 `prefetchDownloadData`，依次预取版本目录和五类在线资源热门列表。
- `frontend/src/app/runtime/useAppRuntime.ts` 每次启动运行时都会调用 `launcher_preload_connector`。前端的去重标记属于当前组件，重新挂载或页面重载会重新触发。
- `ECL/services/connector.py` 已负责节点缓存有效期及在途去重；缓存命中的接口同样按 action 记录开始和完成，因此多次 0ms 日志不证明重复联网。
- `ECL/services/game/resource_search.py` 已持有搜索会话、600 秒空闲有效期及有限并发执行器，不需要新建另一套独立搜索缓存。
- 粘贴日志中一秒内多次出现 `frontend_ready`，表明重复就绪上报或前端重建，单凭日志无法确认是开发热更新还是其他触发。
- `INVALID_RESOURCE_LOADER` 来自 CurseForge 不支持的加载器筛选。前端直接传递实例 primaryLoader，需验证纯净实例或其他类型的规范化；日志没有原始字段，不能断言具体值。
- 上次把共享表面统一设为 16px 背景模糊，同时使生产构建正确保留模糊声明。实际桌面验证的底色 alpha 小于 1，但强模糊、嵌套表面及浅色背景会产生实底观感。默认 Classic 为 0.88，同色两层相当于 0.9856；需要用明显的背景图片验证，不能只看 computed alpha。

## 可选路线

| 路线 | 行为 | 取舍 |
| --- | --- | --- |
| A：后端缓存和调度，在线列表按需加载（推荐） | 取消前端开机扫五类热门列表；节点由后端就绪后一次调度；页面查询复用后端缓存 | 启动安静、无关请求少；首次打开在线分类可能等待网络 |
| B：后端统一完整预热 | 前端只上报就绪；后端统一预热节点、目录及热门列表 | 分类首开更快；启动仍主动联网，需取消、限流、失败退避和目标变更处理 |

两条路线均保留前端渲染状态、用户筛选、选择和界面订阅；网络缓存、有效期、请求合并与失效规则由后端拥有。

## A 的实施范围

1. 删除 App 启动热门列表预取调度，页面挂载时查询实际需要的资源；保留页面在途合并与前端展示状态。
2. 在后端应用生命周期内持有节点预热任务，主窗口首次就绪后只调度一次；不等待网络阻塞首屏，关闭应用时停止调度并释放资源。
3. 沿用 ConnectorService 和 ResourceSearchService，明确缓存键、刷新语义和配置变更失效；不要把前端多个缓存层照搬到后端。
4. 缓存命中作为普通查询保持安静；后台任务区分启动、实际刷新、失败退避与完成，避免每次重复 IPC 都报 INFO 预热。
5. 规范化资源加载器语义：纯净实例不传平台不支持的加载器；已支持类型保持筛选；未知类型按既有错误策略处理，不掩盖真正的输入错误。
6. 账户、头像、实例的前端变更通知保留，避免后端接管网络缓存后重新出现页面刷新才能显示的问题。

## 卡片视觉修正

1. 普通卡片恢复原有半透明视觉，不给所有共享表面强加 16px 模糊；Folia 的既有玻璃效果单独审视。
2. 弹窗、菜单等浮层独立使用模糊变量以保证可读性；避免修改整个元素 opacity，使文字和图标变淡。
3. 检查父面板与子卡片重复底色，对多层容器使用透明内层或轻表面，避免逐层接近实底。
4. 保留透明度设置、亮暗皮肤联动与标题图标；system_shadow 下保持窗口根节点圆角和裁剪为零。
5. 对使用明显背景图片的页面、嵌套卡片及弹窗做修改前后同配置截图验收，确认能看到背景色彩和层次。

## 实施结果

- App 启动预取已删除；`downloadPrefetch` 替换为 `downloadQueries`，保留页面查询的在途合并，不在前端保存热门列表或来源配置的 TTL 缓存。
- ConnectorService 拥有一次性后台节点任务，主窗口就绪时由后端启动；兼容 IPC 复用同一调度状态，前端不再主动调用。仅自定义模式不请求公共节点。
- 节点缓存及在途规则继续复用原服务；搜索复用 ResourceSearchService 的会话。缓存查询和后台预热记录 DEBUG，失败回退继续保留警告。
- 关闭节点服务后停止新请求，迟到结果不能回填缓存；已进入的 HTTP 请求有有限超时，仅短暂等待，未将停止请求表述为网络线程立即退出。
- 后端规范化 `Vanilla` 及加载器大小写和空格；纯净实例与不筛选加载器共享会话，受支持加载器继续筛选，未知加载器继续报错。
- 普通卡片取消强制背景模糊，浮层使用独立模糊变量。用户后续要求恢复卡片透明度，已将亮暗表面恢复为原有 0.88、控件恢复为 0.94，删除新增的 0.12 内层卡片底色覆盖；继续受用户透明度设置控制。
- Folia 的页面和主要卡片取消重复模糊；背景媒体滤镜及额外背景层仍由原有设置控制。标题图标、账户即时刷新、system_shadow 的直角根节点保留。
