# 在线资源版本选择页层级重组实施方案

日期：2026-10-11。

状态：已按用户确认完成实施、质量检查与 Windows 原生验收；本地 main 同步见末节记录。

## 需求与目标

用户提供的苹果皮版本选择页截图，整体布局可用，但筛选含义、下载来源位置、列表层级与表面样式不够一致。选定方案重新组织安装目标、来源及筛选、可用文件之间的层级，同时保留现有安装和另存为行为。

验收目标：

- 用户能直接看懂资源名称、安装目标、文件来源、游戏兼容条件以及具体可选文件。
- 版本与加载器的“不限制”状态，与实例的“未选择”状态使用不同文案。
- 下载来源与其他查询条件组成一个区域，不再单独占据文件列表上方的整行。
- 分组标题突出游戏版本，版本类型、加载器和文件数量作为辅助信息。
- 内容背景、间距与控件对齐一致，主题背景仍能呈现，但不干扰标签和文件文字。
- 960×600、820×600 与更窄窗口均可操作；长实例名、不同语言和多文件组不挤压刷新按钮或产生横向滚动。

## 当前实现与影响范围

调研基线：主仓库 `3f64587`，frontend `9865735`；调研开始时两者工作区干净。

主要实现位于 `frontend/src/components/mods/OnlineModSearch.vue` 与 `frontend/src/styles/views/OnlineMods.css`：

1. 详情页目前依次显示简介卡片、横排筛选栏、直接压在背景上的“选择版本”标题、整行来源下拉、独立圆角版本组。
2. 游戏版本筛选、加载器筛选和实例空选项都引用 `mods.none`。上方游戏版本筛选与下方文件选择标题都使用“选择版本”，概念重复。
3. 版本与加载器下拉固定 130px，实例标签较长，实例下拉使用剩余空间；窄窗口和长翻译容易产生不均衡的换行。
4. 版本组容器与组标题分别绘制背景，叠加后比简介和筛选区域更实；各组都有独立圆角和 10px 间隔。
5. 顶部加载器标签来自搜索结果的 `selectedMod.loaders`，详情筛选与列表来自当前来源的版本文件，存在展示范围不同的情况。
6. 详情共用于 Mod、资源包、光影、数据包、世界资源和整合包，因此不能只处理截图中的 Mod 状态。

需保留的交互：

- `ResourceInstanceSelect` 继续只提供兼容实例及空选择，实例刷新保留现有加载状态。
- 选择实例后，同步游戏版本和加载器；手动筛选与实例不匹配时，清空实例，不自动改装到其他实例。
- 分组仍按游戏版本、版本类型和加载器排列；测试版归并、愚人节排序、所选实例对应分组初始展开沿用当前模型。
- 点击分组标题只展开或收起。直接操作的资源类型点击具体文件后，已有实例进入安装确认，没有实例进入原生另存为。
- 依赖加载、下载进度、数据包目标存档、世界安装以及整合包安装对话框继续使用既有流程。
- 来源切换继续清理旧文件选择并重新加载；迟到响应不能覆盖当前来源。

## 选定布局

保留当前居中内容宽度，页面分为三个区域。下面是布局示意，具体数据以真实资源为准：

```text
┌ 资源信息 ──────────────────────────────────────────────┐
│ 图标  苹果皮                                 Modrinth  百科 │
│       AppleSkin · squeek502                              │
│ 简介                                                     │
└──────────────────────────────────────────────────────────┘

┌ 安装目标与筛选 ──────────────────────────────────────────┐
│ 安装到                                                  │
│ [ 未选择实例／兼容实例名称                          ▾ ] ↻ │
│ 未选实例时的操作说明（适用时显示一行）                    │
│                                                         │
│ 下载来源          游戏版本            加载器             │
│ [ Modrinth ▾ ]    [ 全部版本 ▾ ]      [ 全部加载器 ▾ ]   │
└──────────────────────────────────────────────────────────┘

┌ 可用版本                              当前结果的文件数量 ┐
│ 26.3               正式版  Fabric          3 个文件    ▾ │
│   文件版本号       文件名与既有操作／选中状态             │
│ ─────────────────────────────────────────────────────── │
│ 26.3               正式版  NeoForge        2 个文件    ▾ │
│ ─────────────────────────────────────────────────────── │
│ 26.2               正式版  Fabric          4 个文件    ▾ │
└──────────────────────────────────────────────────────────┘
```

三个区域表达资源、安装上下文、可选文件，不做步骤向导，也不增加额外确认面板。安装目标是可选项，未选择实例不会阻止查看版本或另存为。

### 1. 资源信息

- 保留图标、资源名称、英文名称与作者、简介和外部链接。
- 主名称单独突出；英文名称与作者放在次级信息行，避免与名称和标签挤在同一行。
- 兼容加载器集中在筛选区域和版本分组展示，简介不再显示可能与当前来源文件不一致的搜索结果加载器标签。非 Mod 的资源类型与已有分类信息按需保留。
- 外部链接保持次要按钮样式。窄窗口允许链接换行到独立操作行，不像现有窄屏样式那样直接隐藏全部链接。
- 简介使用次要文字，可显示两行，避免长描述把控制区域推离首屏。

### 2. 安装目标与筛选

- 同一上下文区域中，实例选择占第一行；标签缩短为“安装到”，下拉空选项为“未选择实例”。刷新按钮与下拉同排，不重复显示控制器图标。
- 实例名称沿用当前显示名及必要的游戏版本、加载器、路径区分信息；主控件允许省略长文本，下拉菜单可查看完整内容。
- 对使用直接文件操作的资源，在未选实例时显示简短说明“选择文件后可另存为”；已选实例时不再显示该说明。整合包使用自己的安装流程，不显示安装到已有实例这一行。
- 第二行排列下载来源、游戏版本和加载器，标签放在控件上方，使控件顶部、底部和间距一致。
- 游戏版本空值显示“全部版本”，加载器空值显示“全部加载器”；可搜索、可清空等能力保留。
- 多来源使用现有来源下拉；单来源显示同位置的简洁文本，不绘制可交互的假下拉。
- 仅 Mod 显示加载器条件。只有一个加载器时使用明确的固定值展示，与其他字段对齐；统一 Fabric、NeoForge 等显示名称，内部值保持原协议。
- 文案新增专用 i18n 键，不全局替换 `mods.none`，避免影响其他页面。

### 3. 可用版本列表

- 使用一个统一列表容器承接标题、结果数量、空状态和全部版本组，替换多张独立大圆角卡片。
- 区域标题改为“可用版本”；总数量按当前筛选结果中的文件 ID 去重，避免同一文件支持多个游戏版本时重复统计。每组标注自己的文件数量。
- 分组主文字突出游戏版本；正式版、测试版、愚人节类型及加载器采用次要标签，右侧排列文件数量与展开箭头。
- 行高保持约 40–44px，使用细分隔线和轻微 hover，展开后文件内容缩进；只在列表外边缘保留主圆角，不为每组重复叠加背景。
- 展开的文件行保留版本号、文件名、快照前缀、选中状态和依赖信息。长文件名可省略，但必须能查看完整名称。
- 空状态放在同一列表容器内，说明当前条件下没有可用文件；加载、错误、选中和禁用状态不靠单一颜色区分。
- 继续使用已有 `groupModVersions` 的组键、排序和分组，不增加一层“先选游戏版本，再选加载器”的嵌套导航。

### 4. 样式与响应式

- 三个区域沿用现有 `--ecl-*` 表面、文字、边框与圆角变量；以局部样式统一表面，不修改全局透明度、背景模糊或其他页面的卡片。
- 区域间距以 12–16px 为主，标签与控件间距 4–6px；字段组间距保持一致。
- 默认宽度展示完整三列筛选；窄窗口按实际可用空间改为两列，再改为单列。实例与刷新始终保持独立第一行。
- 分组标题使用可伸缩主列和辅助列；窄屏辅助标签可以换行，箭头保留固定位置，不截断版本号。
- 兼顾 Classic / Folia、亮色 / 深色及背景图片。截图中的组件调试浮窗保留现有行为，验收时临时移开以观察布局，不将浮窗本身纳入本次重构。

## 实施结果

- 详情重排为资源信息、安装目标与筛选、统一版本列表三个区域。英文名称和作者使用次级信息行，来源选择移入筛选网格，实例及刷新位于独立第一行。
- 用“全部版本”“全部加载器”“未选择实例”区分空值语义；未绑定实例说明另存为，空列表说明当前条件下没有可用文件。六种语言文案已更新，没有修改其他页面的通用 `mods.none`。
- 简介不再显示搜索摘要中的加载器标签，实际来源的加载器集中显示在筛选及版本行。组标题拆分游戏版本、版本类型、加载器、文件数量与箭头；总数量按文件 ID 去重。
- 版本列表使用统一表面与分隔线，移除组容器和组标题的双层底色。长文件名可悬停查看，分组和文件增加键盘焦点样式。
- 实例选择组件新增可选的图标、输入标签及菜单样式参数，默认行为保持原样；详情页关闭重复图标，长实例名在主控件省略、菜单内换行查看。
- 筛选网格按可用宽度形成三列、两列或单列；窄窗口外部链接换行保留。全局透明度、模糊、调试浮窗、兼容判定及后端网络协议保持原实现。

原生验收发现并补充修复了整合包的旧状态耦合：共享实例会在版本加载完成时提前打开安装对话框，分组展开也会触发安装入口。整合包现在不自动绑定已有实例，忽略与该安装流程无关的共享目标；加载和展开分组留在版本页，点击具体文件才进入原有独立安装对话框。新增回归在修复前失败，修复后通过，没有添加配置迁移或删除已有记录。
