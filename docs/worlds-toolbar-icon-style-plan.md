# 存档页标题栏采用原理图页图标按钮风格实施方案

状态：用户已确认实施，代码修改、完整检查和实际 Windows 启动器验证均已完成。

## 目标与参照

用户第一张截图是实例设置全屏弹窗的原理图页，第二张是存档页。本次以第一张标题栏为视觉参照，将第二张存档页的文字工具栏调整为相同的图标按钮风格。

| 方案 | 视觉规则 | 选择 |
| --- | --- | --- |
| 图标按钮风格 | 辅助操作为圆形纯图标按钮，主操作为蓝色图标加文字按钮 | 用户已明确选择第一张效果。 |
| 文字按钮风格 | 操作全部使用带边框的文字按钮 | 保留为比较方案，不采用。 |

验收重点是按钮外观与图标，而非强制两页标题栏采用相同换行行数。

## 当前实现

- 原理图页使用 `InstanceResourcesTab.vue`，其标题栏辅助操作为 `NButton quaternary circle size="small"`，图标尺寸 16px；主操作为 `type="primary"` 的小号按钮，图标 13px。
- 存档页使用 `InstanceWorldsTab.vue`，标题栏的刷新、导入、游戏设置、打开存档目录均为默认尺寸的文字按钮。
- 两页卡片已使用相同的主题背景、边框、圆角、阴影，以及标题栏 12px/16px 内边距和 8px 间距。无需改写卡片表面样式。
- 存档页原有世界卡片中的操作已经使用图标按钮，本次仅调整顶部标题栏。

## 具体改动

修改 `frontend/src/components/instances/InstanceWorldsTab.vue`：

1. 搜索框和排序选择框统一为 `size="small"`，与第一张参照页的工具栏控件尺寸一致，保留现有搜索提示、排序选项及绑定逻辑。
2. 将标题栏操作集中到右侧操作区，保留与参照页相同的 8px 按钮间距。
3. 辅助操作使用 `quaternary circle size="small"`：
   - 刷新：`refresh`，16px，保留 `loading` 和原来的 `load()`。
   - 游戏设置：`settings`，16px，保留 `editOptions()`。
   - 打开存档目录：`folder-open`，16px，保留 `openFolder()`。
4. 导入作为主操作放在右侧末尾，使用 `size="small" type="primary"`，配 13px `upload` 图标并保留“导入”文字，继续调用 `importWorld()`。
5. 主操作与辅助操作保留参照页的额外 12px 间隔。
6. 纯图标按钮保留文字提示 `title`，补充明确的 `aria-label`，使鼠标悬停和键盘、辅助技术仍可识别其用途。
7. 保留标题栏在窄窗口下的自然换行。操作区不得挤压搜索框或出现横向溢出。

不修改原理图页、数据包页等已有参照样式，不改左侧导航图标、存档卡片内容和卡片内操作，不修改后端、游戏路径或用户存档。
