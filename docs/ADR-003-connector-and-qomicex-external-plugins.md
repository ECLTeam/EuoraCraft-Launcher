# ADR-003：联机与 QomicEX 兼容分别外置为普通插件

- 日期：2026-11-07。
- 状态：用户已批准实施；本地代码与普通插件已实现，公开网络双端验收及发布尚未完成。
- 决策者：用户。

远端验收补齐：后端 CI 下载并校验插件 wheel 后，仅在测试解释器中离线安装同一完整锁，用于直接导入插件服务的节点回归；主程序 `pyproject.toml` 不恢复 EasyTier 运行依赖，真实 Worker 仍使用插件自己的隔离依赖目录。

## 背景

主程序直接打包联机服务、Florolding 与 EasyTier。现有普通插件的联机接口仍调用宿主实现，无法通过增加插件外壳减少主包。QomicEX 系统插件同时承担实例元数据读取与联机扩展，拥有普通 Worker 没有的路径和宿主接口。

用户要求完整外置联机系统，并将 QomicEX 系统插件降为可独立安装、禁用和卸载的普通插件，联机插件不得强依赖它。

## 选项

1. 主窗口插件页面：迁出联机前后端及专用依赖，补齐普通 Worker 页面接口；保持在启动器内操作。需要修改共享插件契约与路由集成。
2. 独立插件窗口：迁出相同业务，复用现有原生插件窗口；操作转移到单独窗口。

只包装现有宿主联机接口不能达到完整外置与减包目标，不作为本次实现。

## 决策

用户选择选项 1，并指定联机插件的标识和显示名称统一为 `ECL-OnlineGame`。`ECL-OnlineGame` 和 `Qomicex-Compatible` 均使用 API v2 Worker、普通权限审阅与独立 `.eclplugin` 分发；作者均为 `ECLTeam`，显示版本均为 `v1.0.0-beta`，清单版本为 `1.0.0-beta`。

QomicEX 实例元数据与四个 `qml:*` 协议全部归兼容插件。主程序不保留内置 QomicEX 读取器；联机插件独立提供基础联机，通过显式、带版本的可选扩展契约接入兼容语义。兼容插件也能在未安装联机插件时独立提供实例读取。

主程序保留通用插件能力和生命周期监管；新增抽象只服务现有页面注册、嵌套命令数据及完整实例元数据读取三个真实调用需求。原宿主联机实现和旧身份入口同步退出，不增加自动配置或授权迁移。

## 影响

- 主安装包可移除联机专用原生库，最终缩减量以相同配置构建对比为准；共享库按剩余主程序调用保留。
- 用户需单独安装、审阅插件，并重新选择索引、设置节点；原用户文件保留。
- 要补齐普通 Worker 页面、有界结构化命令和完整实例来源 DTO，承担相应跨进程、文件及失效边界验证。
- 主窗口注入仍使用现有 `ui.inject` 信任模型，不宣称新增 DOM 或操作系统沙箱。
- 两插件均安装时兼容能力可用；兼容插件缺失或失效不阻断基础联机。
