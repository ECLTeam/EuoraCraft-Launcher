# 资源详情页局部加载实施方案

状态：用户已选择方案 1「局部加载」并明确确认「开始实施」。功能实现、完整检查、生产构建和真实 Windows 桌面验收已完成。

## 1. 目标与验收标准

解决资源详情加载时整页被白色遮罩冲淡、加载图标悬在筛选区、文件数量及空提示提前显示的问题。

- 标题、图标、简介、外链及筛选卡片按原有表面样式正常显示，加载期间不叠加整页遮罩。
- 「可用版本」标题保持显示；版本内容区使用现有 `UiLoading` 的 `block` 模式，居中显示 24px 转圈及「正在加载版本…」。
- 加载、版本列表、无可用文件提示互斥；加载期间不显示「0 个文件」或其他文件数量。
- 版本区加载内容的最低高度为 120px，沿用主题颜色、字体及现有动画，不新增骨架屏或自定义动画。
- 数据返回后显示分组列表及文件数量；成功返回空列表或筛选无匹配结果时显示原有空提示。
- 加载期间保留安装目标选择、实例刷新、下载源切换、外链和关闭操作；依赖完整版本数据的游戏版本、加载器筛选暂时禁用，加载完成后恢复。
- 当前详情页的六类资源共用此行为：模组、资源包、光影、数据包、整合包、存档。

## 3. 具体修改

### 3.1 详情页模板和状态

修改 `frontend/src/components/mods/OnlineModSearch.vue`：

1. 移除详情页外围的 `UiLoading overlay`，将原 `mod-detail-content` 直接放在 `mod-detail-shell` 下。
2. 在版本卡片中保留标题，文件数量增加 `!detailLoading` 条件。
3. 版本内容按以下顺序渲染：`detailLoading` 时块级加载；否则有匹配分组时显示原列表；否则显示原 `detailNoFiles` 提示。
4. 为局部加载添加 `detail-versions-loading` 类和本地化提示；沿用公共组件默认的图标尺寸和动画。
5. 游戏版本和加载器下拉框绑定 `:disabled="detailLoading"`。下载源切换保持可用，新来源继续进入局部加载，由原请求序号机制处理旧响应。
6. 安装目标仍可选择；请求完成后沿用既有 `syncFiltersFromInstance()` 同步选中实例。隐藏加载中的文件列表，避免用户操作已清空的文件数据；整合包底部按钮继续遵守原有文件选择条件。

保留现有请求、缓存、来源切换、安装确认、前置依赖、文件保存和错误反馈逻辑。请求失败继续使用既有错误提示并结束加载，不在本次引入错误页或重试机制。

### 3.2 页面样式

修改 `frontend/src/styles/views/OnlineMods.css`：

- 为 `detail-versions-loading` 设置 `height: auto`、`min-height: 120px` 和适当内边距，确保内容只在版本卡片标题下方居中。覆盖公共块级加载的百分比高度，避免标题高度参与加载区高度计算并造成下移、裁切。
- 核对移除外围包装后的卡片最大宽度、水平居中、窄窗口及滚动行为；仅在确有需要时调整详情布局规则。
- 沿用现有表面、边框、圆角、字体与主题变量。公共 `Loading.vue`、`Loading.css` 和搜索结果加载不需要修改。

### 3.3 多语言

在 `frontend/src/i18n/locales/` 的六个语言文件增加 `mods.detailLoadingVersions`，中文显示「正在加载版本…」，其他语言提供相应翻译，模板使用翻译键。

## 5. 测试计划

组件回归测试使用可控制完成时间的 Promise，覆盖：

- 六类资源进入详情，项目信息或版本请求未结束时，只有版本区的块级加载存在；详情区没有 overlay、文件行、文件数量或空提示。
- 标题和简介仍显示；游戏版本与加载器控件禁用，下载源和安装目标操作保持可用。
- 有文件响应后加载消失，显示原分组、文件数量及安装/另存为入口。
- 成功返回空集合后才显示零文件及原空提示；筛选无结果仍显示原空提示。
- 切换来源时重新进入局部加载；旧请求完成不能覆盖新数据或提前结束加载，最新请求返回后恢复正常内容。
- 加载中更换安装目标，响应后筛选与当前目标同步；请求失败后加载结束，原错误反馈仍可观察。
- 既有版本展开、文件选择、依赖详情、整合包安装和保存流程测试继续通过。

## 6. 影响与回滚

影响范围为下载页共用资源详情界面的展示及加载期间控件状态，不涉及后端或用户配置迁移。

移除遮罩使仍可使用的控件更加清晰，因此必须验证加载中切换来源、选择实例和关闭详情的现有流程。局部加载随原 `detailLoading` 结束，项目信息较慢时仍会等待二者完成，本次不拆分请求状态。

回滚时还原详情模板、局部加载样式、翻译及对应测试，并将主仓库前端指针还原到改动前的提交即可。
