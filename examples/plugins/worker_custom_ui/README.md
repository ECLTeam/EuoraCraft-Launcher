# 原生独立前端

插件原生独立窗口依赖顶层导航锁定与消息 URI 拦截等隔离原语；这些能力在当前 `pytaurix` 发行中尚未提供，
`ui.windows.open` 会返回 `PLUGIN_UI_ISOLATION_UNAVAILABLE`，窗口不会创建。
以下描述目标形态与消息协议，作为隔离原语落地后重新实现与验收的依据。

入口为包内 UTF-8 单文件 HTML；作者在打包前内联自己的 CSS、脚本、图片或字体。页面处于 opaque sandbox iframe，首版不能直接联网、嵌套页面、启动 worker 或调用通用 Tauri IPC。`ECL.call(method, params)` 只支持当前协议列出的自身命令、设置和任务接口，其他业务通过自己的 Worker 命令完成。

修改问候文本后保存，真实设置应更新且显示自己的命令结果；重复提交会被禁用。撤权、禁用或重载关闭原窗口并作废凭据；已经提交的远程操作不承诺回滚。示例页面中文为第三方自带内容；启动器提供的权限及错误界面仍支持六种语言。Python Worker 不属于操作系统沙箱。
