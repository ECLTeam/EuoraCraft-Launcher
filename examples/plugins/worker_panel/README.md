# 声明式面板 Worker 示例

将本目录按 [v2 包协议](../../../docs/protocols/eclplugin-package-format.md)安装到 Windows x64 启动器。启用后插件只登记设置、一个命令和一个面板，不访问文件、网络或游戏目录，因此不需要任何业务权限。

安装并启用后，在插件管理页点击该插件的「面板」按钮即可打开。面板由宿主渲染，插件不提供 HTML、CSS 或脚本。

## 演示内容

| 节点 | 用途 |
| --- | --- |
| `text` | 说明文字，不解析 Markdown 或 HTML |
| `group` | 带标题的分组容器 |
| `button` | 执行本插件已登记命令，可配置确认文案与色调 |
| `setting` | 复用插件自己的设置定义，写入走宿主设置服务 |
| `list` | 表格，行数据来自数据回调的 `lists.history` |
| `task` | 进度条，数据来自数据回调的 `tasks.progress` |

数据回调 `panel_data()` 返回 `{"lists": ..., "tasks": ...}`，宿主在每次打开面板或执行按钮后按需拉取，不做后台推送。

## 对应契约

- [面板设计](../../../docs/designs/plugin-declarative-panel-design.md)
- 节点上限：单面板 48 个节点、深度 3 层、列表 100 行 8 列
- `panels.register`、`panels.list`、`panels.data` 三个方法，均只要求 `plugin.base`
- 按钮只接受命令名，不能指向其他插件或宿主入口

## 可观察结果

1. 打开面板：看到说明、分组按钮、两个设置项、空的列表与「待开始」进度。
2. 点击「问候一次」并确认：列表新增一行，进度变为已完成 100%，说明文字中的计数递增。
3. 修改「问候前缀」后再执行：新结果使用新前缀。
4. 禁用插件后再次点击「面板」：入口消失；已打开的面板在下一次请求时返回明确的未启用错误。
