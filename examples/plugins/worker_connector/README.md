# 插件所属联机房间

安装、审阅联机许可并启用，从插件的功能面板创建 25565 端口房间，或填写房间码后加入。游戏服务必须先开放相应端口。联机仍依赖现有 EasyTier 节点可用，示例不会自动启动 Minecraft。

房间任务在连接期间持续运行，退出按钮只请求取消；任务实际结束和清理完成才表示退出。用户已有房间时本插件建房被拒绝。撤权、禁用或退出 Worker 将清理本运行房间，不关闭后来建立的用户房间。清理失败时保留句柄，在启动器联机页重试退出。

房客可通过面板发送 JSON 回声请求，房主的同名插件返回业务载荷。示例使用 `connector.protocols.register` 与 `connector.request` 登记并调用私有协议；宿主使用清单名称派生跨设备一致的命名空间，并把协议限定在本来源会话内，载荷上限 16 KiB。相关边界由主仓库的联机运行测试覆盖。
