# 实例只读示例

在插件页安装本目录，打开权限页，允许命令能力和“读取获准实例”。选择整个目录，或展开目录仅选择具体实例，保存审阅后启用。目录授权包含以后新增的实例；单实例授权不会包含兄弟实例。

调用 `instance_reader:summary`，参数为 `{}`，结果为 `{"count":1,"first":"实例名称"}`。插件只使用 `resources.list`、`instances.scan`、`instances.get`，没有宿主路径、账户、启动配置或文件内容接口。查询不会创建游戏配置和统计文件。

撤销授权后，必要许可失效，Worker 停止；旧运行引用不能用于新运行。永久授权绑定当前安装、代码内容和所选物理资源，目录移除或实例同名重建需要重新审阅。会话授权在本次运行结束后失效。

运行平台仍为 Windows x64，Worker 以当前操作系统用户身份运行，不提供操作系统文件/网络沙箱。接口边界见 实例只读 API 方案。
