# Java 查询、校验与安装示例

API v2 插件，只在显式调用命令时执行宿主操作。启用或重启不自动执行 Java；安装是独立的可选能力，不提供删除或自动启动游戏。第三方 Worker 当前只支持已验收的 Windows x64。

1. 在启动器已有 Java 管理中扫描或登记运行时。
2. 安装并审阅示例，逐项选择可读取的 Java，以及可执行版本校验或选用的 Java。两项范围独立，已有登记目标的校验须同时获准。
3. 调用 `inventory`，取得 JSON 中的本运行 `runtime_ref`。其状态为最后登记状态，不代表本次已探测。
4. 向 `validate` 传入该 `runtime_ref`，执行一次固定版本探测；引用不能跨启停复用。
5. 单独允许官方目录查询后调用 `catalog`，取得当前平台推荐主版本的 JRE 包摘要；固定官方来源不需要通用网络授权。
6. 允许“安装并使用官方 Java”后，向 `prepare_install` 传入明确选择的 `package_ref` 和本次 `mutation_key`，审阅计划。向 `install` 传入计划的 `plan_ref` 和另一稳定去重键，只提交所属任务。
7. 向 `status` 传入 `operation_ref`。只有实际安装、校验和登记完成才会返回 `runtime_ref`，本运行可据此校验或在 `game.launch.options.runtime_ref` 中选用；不得把 queued 当成功。同次安装重试保留去重键，不能接管用户或其他插件的任务。

安装许可只允许使用本运行在该许可下新安装并核验的运行时，不等于选用所有全局 Java。撤权、插件重载、身份或文件变化使原引用失效；已经安装的文件保留，不因撤权删除。

命令返回首个分页；完整分页调用及错误、撤销、路径隔离和截止语义以[插件包格式](../../../docs/protocols/eclplugin-package-format.md)为准。未授权、目录失败、Java 已变更或超时会明确失败，不返回空列表冒充成功。
