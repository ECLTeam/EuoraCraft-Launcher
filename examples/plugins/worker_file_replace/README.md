# 私有文件按版本替换

调用replace时显式传入当前run的root_ref、已有文件name、合法取得的expected_etag、新text和保留的mutation_key。
首次空间或缺失目标不会自动新建；私有文件操作属于基础能力，上传及结果FileView均绑定同一原始运行准入。

替换先保留原对象，再不覆盖发布新内容，目标名称可能短暂缺失，不承诺外部路径读取者的一次原子覆盖。
成功替换不提供旧版本撤销；失败若原位置被后来文件占用，会保留原备份，通过启动器“文件恢复”处理。
可以不覆盖恢复原位置、明确另存原文件，或确认永久丢弃原备份；插件不能调用主窗口恢复管理接口。

用status查看实际state/effect/cleanup_pending。提交等待失败使用原键查询mutations.get，不换键重做。
示例为begin、各chunk与commit派生固定键；接受任务后的abort不会取消该任务。重试完整命令前先确认commit回执，
避免尝试已经交给任务的上传。加载、卸载及停止不会自动替换文件或继续旧上传。

仅支持Windows x64、本地NTFS、自身私有空间、平铺普通单链接文件，旧/新文件均至多8 MiB。
